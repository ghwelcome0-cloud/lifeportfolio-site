### 승인과 설정은 다른 문제다

사용자의 진행·조건부 배포 권한은 확인했다. 그러나 실제 결제사 테스트 설정과 시험 결과, 실물 기기 증빙, 최종 head의 역할별 승인 메시지/링크, 성공 preview 산출물은 권한 문구로 대체할 수 없다. 시크릿을 채팅에 붙여 넣게 요구하지 않고 승인된 비밀 저장소/테스트 환경을 통해 연결해야 한다. 확인 범위에서 설정 조합을 확보하지 못한 것이며, 모든 계정에 sandbox가 없다고 단정하지 않는다.

### 안전한 다음 실행 순서

1. G05 정책 초안·라이선스·산출물을 최종 head로 묶어 실제 역할별 검토를 받는다. 가짜 승인 블록이나 PR240 옛 승인을 사용하지 않는다.
2. G07 시험 환경에서 PSP의 권위 있는 거래 확인 계약을 확보하고, G08 주문별·원자적 권리 반영/복구와 읽기 경로를 맞춘다.
