## 2. ②축 원값 확정 — 75 (70 아님)

1차 보관본 `docs/벤치마킹_리포트_5축_점검_2026-07-25.md` L41 표에 ②축이 **70** 으로 적혀 있습니다. 이는 **표 오기**입니다.

리서처 task #7 판정 (근거 포함):

| 근거 | 내용 |
|---|---|
| 산술 검증 | `62+75+78+85+58 = 358 / 5 = 71.6` ✅ / `62+70+78+85+58 = 353 / 5 = 70.6` ❌ — 보관본 자신이 평균을 71.6 으로 적었으므로 70 이면 내부 불일치 |
| 커밋 이력 | 최초 추가 커밋부터 불일치 포함 ⇒ 후대 변경이 아니라 **보관본 생성 시 오기** |
| 교차 확인 | 2차 의뢰서 · 2차 심층보고서 원문 · 결과 프로젝트 기록 **모두 `62/75/78/85/58 = 71.6`** 일관 사용 |

⇒ **②축 Before 원값 = 75 확정.**

권고 (리서처): 보관본의 70 을 75 로 정정하되 "기존 표 오기 정정" 이력을 남기고, `internal_only` · 대외 인용 금지는 유지.
※ 본 문서는 정정 이력 기록만 담당하며, 보관본 파일 자체 수정은 별건입니다(배포헌법 제14조 — 교체가 아닌 추가).

## 6. 자기 반박

`docs/공개채점표_규격서_v0-draft_2026-08-17.md` §7 요건("자기 반박이 비어 있으면 반려한다")을 본 문서에도 자율 적용합니다.

1. **본 문서는 원문 HTML 을 직접 열어 작성한 것이 아닙니다.** 리서처의 task #7 제출 내용과 원문 인용에 의존합니다. 따라서 §1 점수표는 **2차 전달 정보**이며, 원문 대조는 R-11 회수 시 수행해야 합니다.
2. **가중 평균의 가중치가 미확인입니다.** `71.6` 과 `78.0` 이 단순 산술평균과 일치하는지 본 문서는 검증하지 않았습니다(1차는 `358/5 = 71.6` 로 일치 확인. 2차는 `73+79+83+88+67 = 390/5 = 78.0` 로 일치). ⇒ 실제로는 **단순 산술평균**으로 계산 재현됩니다. 그러나 원문이 "가중"이라 표기한 이유는 미확인입니다.
3. **"90점 목표"의 채점 주체가 3차에서 동일할지 보장되지 않습니다.** 평가자가 달라지면 점수 비교 가능성이 훼손됩니다. 이 위험은 현재 통제되지 않았습니다.
4. **본 문서는 개선을 증명하지 않습니다.** 기준선만 기록합니다. 개선 증명은 3차 외부 재평가로만 가능합니다.
