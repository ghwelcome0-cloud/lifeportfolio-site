# G16 판정 규칙 — 결과 열람 전 사전 고정

- 업무 ID: FAISE-20260908-Q90-01 · 작성: 총괄 · 2026-10-08
- 지위: 대원칙-E-2(봉인 후 판정)에 따라 **judge 결과를 열기 전에** 총괄이 고정하는 판정 산식. 동결 계약(contract `c25fff3a…`, scorer `aa64b1d3…`)이 이미 정한 것은 그대로 따르고, 이 문서는 계약이 총괄 판단에 맡긴 **적용 순서와 미달 시 행동**만 정한다. 계약과 충돌하면 계약이 우선한다.
- 이 문서의 hash는 생성 승인 요청서에 함께 결박한다. 결과 열람 후 수정 금지.

## 1. 입력

| 항목 | 출처 |
|---|---|
| 축별 원점수 (A1~A7, release × judge × 회차) | judge1·judge2 각 2회, 블라인드 배정표 |
| 축별 출처 태그 | 직접기술 / AI판단 / 기존증거(ref) / 미측정 / 비적용 |
| negative 12회 × 6확인항목 | 하네스 측정값 (`true`/`false`/`null`) |
| A6 셀 288개 (1440·390) | 하네스 측정값, `min` 반영 |
| judge 간·회차 간 일치도 | scorer 산식 |

## 2. 축 점수 확정 순서 (release마다 동일)

1. **negative 게이트 먼저.** 12회 중 하나라도 6개 확인항목이 `true`가 아니면(`false` 또는 `null`) 그 release의 ALT 총점은 **차단(blocked)**. 축 점수는 기록하되 총점을 내지 않는다. (계약 negative_execution)
2. 축마다 judge 4개 값(2명×2회)의 **중앙값**을 축 점수로 한다. 계약 scorer가 다른 집계를 정하면 그것을 따른다.
3. 축 안에 `미측정` 세부항목이 있으면 그 축은 **부분측정**으로 표기하고, 미측정 항목의 배점만큼 **축 상한을 낮춘다**(예: A6 15점 중 A6.5 3점 미측정 → A6는 `__/12 (3점 미측정)`). 0점으로 채우지 않고, 분모에서 조용히 빼지도 않는다. 성능표에 그대로 노출.
4. judge 불일치: 같은 축에서 4개 값의 범위가 배점의 1/3을 넘으면 adjudicator에게 넘기고, 조정 결과 1개 값으로 대체. adjudicator도 결과 열람 전 배정된 사람만.

## 3. 총점과 90점 판정

- 총점 = 7축 점수 합. 만점 100. 부분측정 축이 있으면 **총점도 `__/상한`으로 표기**하고 100점 환산을 하지 않는다.
- **90점 달성 조건 (모두 충족)**
  1. negative 게이트 통과 (release 전체)
  2. 미측정 없는 상태에서 총점 ≥ 90, **또는** 부분측정 상태라면 `점수/상한 ≥ 0.90` 이면서 미측정 배점 합계 ≤ 5점
  3. **필수축**: A7(보안) ≥ 7/10, A2(자기인식) ≥ 11/15, A5(신뢰감) ≥ 11/15. 총점이 90을 넘어도 필수축 하나가 미달이면 **미달성**.
  4. judge 간 일치도가 scorer 기준 이내 (불일치 축은 adjudicator 조정 후)
- 위 2·3의 임계값은 계약이 더 엄격한 값을 정했으면 계약값을 쓴다.

## 4. 두 버전 비교 (G14)

- 같은 사례·같은 judge·같은 하네스·같은 조건에서만 축별 차이를 적는다.
- 한쪽이라도 그 축이 `미측정`/`부분측정`이면 차이 칸은 `비교 불가`.
- 개선판이 기존판보다 낮은 축이 있으면 **숨기지 않고 그대로 적는다.**
- "개선됐다"는 문장은 차이가 judge 불일치 범위(1/3 배점)를 넘을 때만 쓴다. 그 안이면 "차이 없음(판정 범위 내)".

## 5. 미달 시 행동

1. 근거가 가리키는 **가장 낮은 필수축 → 가장 낮은 일반축** 순으로 개선 대상 1개를 정한다. 여러 축을 동시에 고치지 않는다.
2. 개선은 **새 commit**으로 하고, 새 candidate로 **재동결**(20키 object hash 재산출, Method/Peer 수락)한 뒤 **동일 사례·동일 judge·동일 하네스**로 재채점한다.
3. 재채점 시 기존판 점수는 재사용한다(재생성 안 함).
4. 사례·축·배점·judge를 바꿔서 통과시키지 않는다. 바꾸고 싶으면 Q90 다음 사이클(Q90-ALT-v2)로 넘긴다.

## 6. 공개 성능표(G17)로 넘길 때

- 축별 점수에 출처 태그를 반드시 붙인다.
- 부분측정·미측정·비적용·negative 차단 여부를 **표 위**에 먼저 적는다(E-1).
- "90점 달성" 문구는 §3의 4조건을 모두 충족했을 때만. 하나라도 아니면 "미달성(사유)".
- 과거 5축 78점은 어디에도 넣지 않는다.
