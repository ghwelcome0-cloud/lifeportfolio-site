## 0. 이 문서가 해결하는 문제

지금 우리에겐 **채점표 관련 지시가 두 갈래로 흩어져 있다.**

| | 출처 | 내용 | 성격 |
|---|---|---|---|
| **갈래 A** | 총괄 발주 【과제 2】-1 (2026-08-17 01:27) | "공개 비교표에 쓸 **평가 축 6~8개**" + 예시 8개 | 실무적 · 오늘 당장 잴 수 있음 |
| **갈래 B** | 문서[2] §6-2 (2026-07-31) | AERA/ITC/EFPA 기반 **공인 채점표 요건 4개** | 학술적 · 인증 가능성의 근거 |

**둘을 따로 두면 둘 다 실패한다.**
- A만 하면 → "너희가 정한 축 아니냐"는 반박에 무너진다. 인증 근거가 없다.
- B만 하면 → 심리측정 학술 기준이라 **우리도 경쟁사도 대부분 N/A**가 되어 비교표가 텅 빈다.

**대표님 지시는 이 둘을 하나로 합치라는 것이다.** 이 문서가 그 통합 규격이다.

**통합 방식:** 갈래 A의 축을 **표의 뼈대**로 쓰고, 갈래 B의 요건 4개를 **모든 축에 적용되는 채점 규칙**으로 건다.

## 1. 설계 원칙 — 왜 이 형태여야 하는가

### 1-1. 머스크식 비교가 성립하는 조건은 단 하나

대표님이 예로 드신 그록/클로드/GPT 비교표가 설득력을 갖는 이유는
"그록이 좋다"고 말해서가 아니라 **누구나 같은 벤치마크를 돌려 반박할 수 있기 때문**이다.

> **따라서 이 채점표의 유일한 합격 조건:**
> **제3자가 우리 도움 없이 같은 절차를 밟아 같은 점수에 도달할 수 있는가.**

이 조건을 만족하지 못하는 축은 **아무리 우리에게 유리해도 표에서 뺀다.**

### 1-2. 우리에게 유리한 축을 넣으면 안 되는 이유

축을 우리 강점에 맞춰 고르는 것을 **cherry-picking** 이라 하고,
비교표에서 이것이 발각되면 **표 전체가 무효가 될 뿐 아니라 기업 신뢰가 손상된다.**

방지 장치 3개를 규격에 박는다.
1. **축은 우리 제품을 보기 전에 정의한다** — 각 축의 근거를 외부 공개 기준에서 가져온다(§3).
2. **지는 축을 반드시 포함한다** — 최소 2개 이상(§5-3).
3. **축 선정 이유를 공개한다** — 왜 이 축들인지, 왜 다른 것은 뺐는지 기록(§3-3).
   ※ v0.2 기준 **채점 축 10개(A1~A7·A9~A11) + 참고 열 2개(A0·A8)**. 개수 자체는 확정치가 아니며
   GTM 리드의 채택/수정/폐기 판단으로 바뀔 수 있다 — **대표 지시 ② "개수에 연연하지 말 것".**

### 1-3. "인증 가능"의 정확한 의미 (대표님 표현의 번역)

대표님이 쓰신 **"인증이 가능한"** 을 우리는 두 단계로 나눠 쓴다. 섞으면 허위가 된다.

| 단계 | 의미 | 지금 가능한가 |
|---|---|---|
| **L1 자기검증 가능** | 절차·원자료·환산식을 공개해 **제3자가 재현**할 수 있다 | ✅ **지금 가능. 이 문서의 목표.** |
| **L2 외부 인증** | 외부 기관이 심사하고 인증서를 발급한다 (EFPA 리뷰 등) | ❌ **우리는 현재 없음.** 있다고 쓰면 허위 |

> **문안 규칙:** "제3자 재현 가능한 공개 채점표" ⭕ / "인증받은 평가" ❌
> ([8] 용어분리지침과 동일한 논리 — 재현성과 신뢰도를 구분하듯, 재현성과 인증을 구분한다.)

#### ★ v0.2 개정 — L2를 "쓰지 말 것"에서 "채점할 것"으로 바꾼다

v0에서 L2는 **문안 금지어**로만 다뤘다. 즉 "우리에게 없으니 언급하지 말자"였다.
대표님은 이를 뒤집으셨다. **없다는 사실 자체를 표에 적으라**는 것이다.

**왜 이것이 더 강한가 — 세 가지 이유**

1. **고객 신뢰**: 우리가 지는 칸이 표에 있어야 나머지 칸도 믿긴다.
   전 축 우세인 표는 광고로 읽힌다(§1-2와 같은 논리).
2. **동기부여**: 표에 `➖` 로 남아 있는 칸은 우리 로드맵이 된다.
   대표님 표현 그대로 **"향후 검증을 받기 위한 동기부여"** 다.
3. **업계 표준과 일치**: LLM 비교표들도 **SOC 2 / ISO 27001 / HIPAA 준수 여부**를
   축으로 쓴다(§1-4 근거). 제3자 인증 보유 여부는 이미 표준 비교 항목이다.

⇒ **§3-0 에 신설 축 `A0 제3자 검증 이력` 을 둔다.**

> **주의(허위 방지):** A0를 넣는다고 우리가 인증을 받은 것이 아니다.
> A0 는 **"누가 인증을 받았는지 사실대로 적는 칸"** 이고, 우리 칸은 정직하게 `➖` 다.
> 이 칸을 채우면서 우리 점수를 올리려는 시도는 규칙 2·5 위반이며 반려 사유다.

### 1-4. ★ v0.2 신설 — LLM 비교 채점표 벤치마킹 (대표 지시 ②)

대표님이 지목하신 **그록·제미나이·클로드·챗GPT 비교표**를 실제로 조사했다.
아래는 추정이 아니라 **확인한 실물의 구조**다.

#### (가) Artificial Analysis — 방법론 공개형의 정본
출처: `artificialanalysis.ai/methodology` · `/methodology/intelligence-benchmarking` (2026-08-17 확인)

| 그들이 한 것 | 우리가 가져올 것 |
|---|---|
| 9개 평가를 **가중 평균**하고 **가중치를 표에 명시** (Agents 34% / Coding 24% / Scientific Reasoning 24% / General 18%) | 규칙 1-④ 가중치를 **표 안에** 적는다. 별첨으로 빼지 않는다 |
| **95% 신뢰구간 < 1%** 를 함께 공개 | **우리 측정의 오차·한계도 함께 공개**한다 |
| **"Like all evaluation metrics, it has limitations…"** 한계를 스스로 적음 | §7 자기반박 절 유지 — **비어 있으면 반려** |
| Multilingual / Vision / Math 는 종합지수에 **섞지 않고 따로** 보고 | **성격이 다른 축은 합산하지 않는다** (우리 §6 "네 번째 체계"와 동일 논리) |
| 가격을 **환산식 공개(캐시히트:입력:출력 = 7:2:1)** 로 점수화 | **A8 재검토 근거** → §3-4 |
| 4대 원칙: **Standardized · Unbiased · Zero-Shot · Transparent** | 규칙 3(동일 절차 적용)의 상위 근거로 채택 |

#### (나) 상용 5종 비교표 — 고객이 실제로 궁금해하는 축
출처: `aizolo.com/blog/chatgpt-vs-grok-vs-gemini-vs-claude-vs-perplexity/` (2026-08-17 확인)
명시된 채점 축 9개: **accuracy, coding quality, writing quality, research depth, reasoning,
speed, context window, pricing value, privacy/enterprise readiness**

★ **이 표에서 배울 점 3가지**

1. **"How We Tested" 절을 먼저 쓴다.** 무엇을 어떤 순서로 시켰는지 공개한 뒤 점수를 낸다.
   → 우리 §5-2 절차를 **표와 같은 페이지에** 싣는다. 별도 문서로 숨기지 않는다.
2. **"어느 것도 전 항목 1등이 아니다"를 표 서두에 명시한다.**
   ("no single one wins every category") → 이것이 표의 신뢰를 만든다. §1-2와 동일.
3. **제3자 인증(SOC 2 · ISO 27001 · HIPAA)을 비교 항목으로 쓴다.**
   → **대표님의 L2 체크 지시가 업계 표준과 정확히 일치한다는 실증.** A0 신설의 외부 근거.

#### (다) ★ 벤치마킹으로 드러난 우리 v0의 빈칸 (축 충분성 점검)

대표님 지시: **"채점 축 개수에 연연하지 말고, 정말 비교 채점하기에 충분한 축들이 반영됐는지가 중요."**
그래서 개수를 세지 않고 **LLM 표에는 있는데 우리 표엔 없는 것**을 찾았다.

| LLM 표의 축 | 우리 v0 | 판정 |
|---|---|---|
| privacy / enterprise readiness | A6 데이터 투명성 | 있음 — 단 **제3자 인증 칸 없음** → **A0 신설** |
| accuracy (정확성) | ❌ 없음 | ⚠ 우리 제품은 결정론 엔진이라 "정확도" 대신 **A9 응답–결과 일관성** 으로 번역 |
| writing quality / research depth (산출물 자체 품질) | ❌ 없음 | ⚠ **A10 산출물 품질** 신설 — 고객이 가장 궁금해하는 것("그래서 결과물이 좋아?") |
| speed (체감 성능) | ❌ 없음 | ⚠ **A11로 흡수** — 다만 웹 서비스라 "응답 속도"보다 **완주율/소요시간**이 적합 |
| context window | 해당 없음 | ➖ LLM 고유 축. 우리 제품에 대응물 없음 → **탈락 사유로 §3-3에 기록** |
| pricing value | A8 (점수 없음) | → **§3-4에서 조건부 점수화 재검토** |

> **총괄 판단:** v0의 8축은 **"우리가 지킨 규범"** 위주였고,
> **"고객이 실제로 궁금해하는 것"** — 결과물이 쓸만한가, 끝까지 할 수 있는가 — 이 비어 있었다.
> 대표님이 **"전문성과 신뢰도 평가축 점수를 높였으면 좋겠다"** 고 하신 것이 정확히 이 지점이다.
> **규범 준수 축만 있으면 전문가는 인정해도 고객은 설득되지 않는다.**

## 2. 채점 규칙 (문서[2] §6-2 계승 — 전 축 공통)

**모든 축은 예외 없이 아래 규칙을 따른다.**

### 규칙 1 — 항목마다 4가지를 명시한다
① **기준 출처** (왜 이것이 평가 항목인가 — 외부 근거)
② **요구 증거 유형** (무엇을 제출해야 점수가 인정되는가)
③ **1~5점 레벨 정의** (각 점수의 조건을 문장으로)
④ **가중치**

### 규칙 2 — 데이터 없는 항목은 0점이 아니라 `N/A(평가 유보)`
0점은 "했는데 나쁘다"는 뜻이고 N/A는 "확인 못 했다"는 뜻이다. **둘을 섞으면 그 표는 거짓말이 된다.**
경쟁사 정보를 못 찾았다고 0점을 주면 우리에게 유리하게 왜곡된다. **이것이 가장 흔한 조작 경로다.**

### 규칙 3 — ★ 동일 채점표를 벤치마크에도 똑같이 적용한다
객관성의 근거는 이것 **하나뿐**이다. 우리에게만 관대한 기준을 적용하는 순간 표는 광고가 된다.
**같은 사람이, 같은 날, 같은 절차로, 같은 순서로 채점한다.**

### 규칙 4 — 최종 점수 = `평가 가능 항목 점수` + `유보 항목 목록`, 환산식 공개
유보 항목을 숨기고 총점만 내놓으면 안 된다. **"8축 중 6축 평가 완료, 2축 유보"** 를 표에 함께 싣는다.

### 규칙 5 (신규 · 총괄 추가) — 채점 원자료를 보존한다
각 셀의 점수 옆에 **증거 링크(URL·스크린샷 파일명·측정 로그)** 를 남긴다.
증거 없는 셀은 `N/A` 로 강등한다.

> **근거 — 대표 교훈 13:** "로그의 OK 를 믿지 말고 산출물을 되읽어라."

### ★ 3-0. (v0.2 신설) A0 — 제3자 검증 이력 · 체크 표시 열

**대표님 지시 ②의 직접 산출물이다.** 다른 축과 성격이 다르므로 A0 로 따로 둔다.

| 항목 | 내용 |
|---|---|
| **무엇을 재는가** | 이 서비스가 **외부 기관의 심사·인증·학술 리뷰**를 받은 이력이 있는가 |
| **기준 출처** | EFPA Test Review Model · Buros MMY(정신측정 리뷰) · ISO 27001 / SOC 2(정보보호) · 학술지 게재 |

| **점수화 여부** | ⚠ **점수 없음. 체크 표시만.** (이유는 아래) |

**표기 규칙 — 4가지만 쓴다**

| 표기 | 의미 | 반드시 함께 적을 것 |
|---|---|---|
| ✅ | 제3자 검증 **보유** | **기관명 · 연도 · 확인 가능한 URL** (3개 전부 없으면 ✅ 불가) |

**왜 점수를 매기지 않는가 (중요)**

인증 1건과 2건 중 무엇이 더 나은지는 **기관 성격에 따라 다르다.**
ISO 27001(정보보호)과 EFPA(측정 타당도)는 서로 다른 것을 보증하므로 **합산이 성립하지 않는다.**
→ 대표 교훈 10 **"지표가 다르면 비교가 성립하지 않는다"** 를 그대로 적용한다.
숫자를 만들면 자의적이 되므로 **사실만 체크**한다. (A8과 같은 처리)

**우리 칸을 어떻게 적는가 — 반드시 이대로**

> 인생포트폴리오 : **➖** (2026-08 기준 외부 기관 인증 없음. 현재는 L1 자기검증 공개로 대체)

이 문장을 표에 그대로 싣는다. **가리거나 빈칸으로 두지 않는다.**
이유는 §1-3 v0.2 개정 3항 그대로다. 지는 칸이 있어야 이기는 칸이 믿긴다.

> **리서처에게 (R-4 신규 과제):** 비교 대상 각 서비스의 A0 칸을 채우되,
> **"없다"고 단정하기 전에 반드시 해당 인증기관 DB를 직접 확인**하십시오.
> 공식 사이트에 안 적혀 있다는 것만으로 `➖` 를 주면 규칙 2 위반입니다. 확인 못 했으면 `❓` 입니다.

### 3-2. ★ GTM 리드가 판단할 것 — 축의 성격이 네 종류로 섞여 있다

| 종류 | 해당 축 | 특징 | 위험 |
|---|---|---|---|
| **외부 기준 유래** | A1 A2 A3 A6 A7 A9 | 우리가 만들지 않은 기준. 반박 어려움 | 없음 — **표의 신뢰 기반** |
| **우리 차별화 유래** | A4 A5 | 우리가 잘하는 영역 | ⚠ **cherry-picking 의심을 받을 수 있음** |
| **고객 관심 유래** (v0.2 신설) | A10 A11 | 고객이 실제로 궁금해하는 것 | ⚠ **주관 개입 위험 최대** → 루브릭·채점자 분리로 방어 |
| **사실 기술** | A0 A8 | 점수화가 아니라 사실 나열 | 점수를 매기면 자의적이 됨 |

**총괄 판단 (GTM 리드는 이를 검토하고 반박해도 된다):**
- A4·A5 는 **넣되, 우리가 만든 축임을 표에 명시**한다. 숨기면 발각될 때 더 큰 손해다.
- A0 는 **체크 표시만.** 점수화하면 성격이 다른 인증을 합산하게 된다(교훈 10).
- A8 은 §3-4 의 조건을 **충족할 때만** 점수화한다. 미충족 시 v0 방침대로 사실만 병기.
- **A10 은 채점자를 분리하지 못하면 아예 넣지 않는다.** 자화자찬 축이 되면 표 전체가 무효다(교훈 25).

⇒ **채점 축은 A1~A7 + A9~A11 (10개), 참고 열은 A0·A8 (2개).**
   단, **개수는 결론이 아니다.** GTM 리드는 §3-3 에서 **각 축을 채택/수정/폐기 판단**하고,
   **"이 표로 비교 채점하기에 충분한가"** 에 답해야 한다 — 대표님이 물으신 것이 이것이다.

### ★ 3-4. (v0.2 신설) A8 가격 축 — "점수 없음" 판단의 재검토

v0에서 총괄은 A8을 **"주관이 개입하므로 점수화하지 않는다"** 고 판단했고, 대표님도 승인하셨다.
그런데 §1-4 (가) 조사에서 **반례**를 찾았다. Artificial Analysis 는 가격을 점수화한다.

**그들이 주관을 배제한 방법 = 환산식과 가정을 전부 공개**
- 혼합 단가 계산에 쓴 비율(캐시히트:입력:출력 = 7:2:1)을 **가정으로 명시**
- 실제 소비량 × 단가로 **Cost per Task** 를 산출, 그 가중치도 종합지수와 동일하게 맞춤

⇒ **주관을 없애는 방법은 "점수를 안 매기는 것"만이 아니다. "계산 과정을 전부 공개하는 것"도 된다.**

**따라서 A8은 아래 3조건을 ★전부★ 충족할 때만 점수화한다. 하나라도 미달이면 v0 방침(사실만 병기) 유지.**

| # | 조건 | 확인 방법 |
|---|---|---|
| 1 | **환산식을 표에 공개** (예: 1만원당 산출물 페이지수·문항수 등 무엇으로 나눌지) | 표 안에 수식이 보이는가 |
| 2 | **가정을 명시** (예: "1회 이용 기준", "구독제는 1개월 기준으로 환산") | 가정 문장이 표 각주에 있는가 |
| 3 | **동일 환산식을 경쟁사에도 그대로 적용** (규칙 3) | 우리에게만 유리한 분모를 쓰지 않았는가 |

> **GTM 리드 과제 G-4 (신규):** 위 3조건을 충족하는 환산식을 설계할 수 있는지 판단하고,
> **불가능하면 "불가능한 이유"를 적어 v0 방침을 유지**하십시오.
> ★ 억지로 만들지 마십시오. **못 하겠으면 못 한다고 적는 것이 정답입니다.**

### 5-2. 채점 절차 (재현 가능성의 실체)

```
1. 측정 환경 고정 및 기록
   · 날짜 · 브라우저/버전 · 뷰포트(PC 1440 / MO 375) · 도구 버전(Lighthouse, axe)
2. 대상별로 동일 순서 수행
   · 로그인 불필요한 공개 페이지만 사용 (접근 조건이 다르면 비교 불성립)
3. 축 A1~A7 을 ★같은 순서로★ 채점
   · 축 하나를 전 대상에 대해 끝내고 다음 축으로 (대상별로 몰아 채점하면 편향된다)
4. 각 셀에 증거를 첨부 (규칙 5)
5. 증거 없는 셀은 N/A 로 강등
6. 총점 = 평가 가능 항목 합 / 만점 × 100, 유보 목록 병기
7. ★자기 반박★ — "이 표를 공격한다면 어디를 칠 것인가" 를 적는다
```

**절차 3의 근거:** 대상별로 채점하면 앞 대상의 인상이 뒤 대상에 전이된다(halo effect).
축별로 가로로 채점하면 같은 잣대가 유지된다. **이것이 규칙 3의 실행 형태다.**
