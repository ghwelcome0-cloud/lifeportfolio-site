# 3차 외부 재평가 의뢰서 개정안 — 홈페이지 ⑥축 추가

- 대상 파일: `docs/심층리서치_5축재평가_프롬프트_2026-07-31.md`
- 개정 목적: 기존 5축의 정의와 비교 기준을 유지하면서, 홈페이지 이용편의성·시각품질을 ⑥축으로 별도 신설
- 개정 방식: 기존 5축은 제공된 고객 대면 지면 전문으로 평가하고, ⑥축은 실제 사이트를 PC 1440px 및 모바일 390px에서 직접 관찰해 평가
- 편집 원칙: 아래 **변경 후** 문안은 의뢰서에 그대로 반영할 수 있는 완성형이다.

## 1. §5 평가 대상 문구 대조

### 변경 전

> ## 5. 평가 대상 — **개선 후 실제 고객 대면 지면 전문 (추측 금지 · 이 텍스트로만 평가)**
>
> ※ 표 정렬·공백은 PDF 레이아웃을 텍스트로 옮긴 결과이며, 실제 지면은 조판된 상태입니다. **지면 조판 자체가 아니라 문장·구조·실행 지시를 평가**해 주십시오.

### 변경 후

> ## 5. 평가 대상 — **개선 후 실제 고객 대면 지면 전문 + 실제 홈페이지 (관찰 범위 밖 추측 금지)**
>
> 이번 3차 재평가는 평가 대상을 다음 두 범위로 구분합니다.
>
> **A. 기존 5축 평가 대상:** 아래에 제공된 개선 후 실제 고객 대면 지면 전문
>
> - ① 첫인상 직관성
> - ② 자기인식 정확도·공감
> - ③ 바로 실행가능성
> - ④ 자산화·축적 연결성
> - ⑤ 전문성·신뢰감
>
> 기존 5축은 1차·2차 평가와의 비교 가능성을 보존하기 위해 축의 정의, 평가 범위, 가중 방식 및 판정 관점을 변경하지 마십시오. 아래 전문에 제시되지 않은 내용은 있다고 가정하지 말고, 제공된 텍스트에서 직접 확인되는 근거만으로 평가해 주십시오.
>
> ※ 표 정렬·공백은 PDF 레이아웃을 텍스트로 옮긴 결과이며, 실제 지면은 조판된 상태입니다. 기존 5축에서는 지면 조판 자체가 아니라 문장·구조·실행 지시를 평가해 주십시오.
>
> **B. 신규 ⑥축 평가 대상:** 실제 홈페이지 `https://lifeportfolio.co.kr`
>
> ⑥ 홈페이지 이용편의성·시각품질은 기존 5축에 편입하거나 기존 축의 정의를 바꾸지 않고, 별도의 추가 축으로 평가해 주십시오. 평가자는 실제 사이트를 직접 열어 아래 두 조건을 각각 관찰·채점해야 합니다.
>
> - PC: 뷰포트 너비 1440px
> - 모바일: 뷰포트 너비 390px
>
> 같은 브라우저 계열과 같은 평가 시점에서 두 조건을 각각 점검하고, 브라우저명·버전, 운영체제, 평가 일시와 실제 확인한 URL을 기록해 주십시오. 로그인·결제·권한 또는 외부 서비스 제약으로 확인하지 못한 경로는 추정해 채점하지 말고 **미확인**으로 표시하며, 확인하지 못한 이유를 적어 주십시오.
>
> ⑥축은 PC와 모바일을 각각 독립적으로 채점한 뒤, 두 점수 중 **낮은 점수**를 ⑥축 최종 점수로 채택합니다. 평균값을 사용하지 마십시오.
>
> `⑥축 최종 점수 = min(PC 1440px 점수, 모바일 390px 점수)`
>
> 여기서 “추측 금지”는 실제 사이트를 보지 말라는 뜻이 아닙니다. 기존 5축은 제공된 지면 전문, ⑥축은 평가자가 직접 관찰한 실제 사이트 화면·동작과 본 의뢰서에 첨부된 실측 자료를 근거 범위로 삼으라는 뜻입니다. 직접 관찰하거나 자료로 확인하지 못한 기능·성능·접근성 상태는 좋거나 나쁘다고 추정하지 마십시오.

## 2. 신규 삽입문 — ⑥축 평가 지시문

아래 문단을 §5의 평가 대상 설명 뒤, 실제 평가 자료 앞에 새 하위 절로 삽입한다.

### 변경 전

> 해당 없음 — 기존 의뢰서에는 ⑥축 평가 지시문이 없습니다.

### 변경 후

> ### 5-1. ⑥ 홈페이지 이용편의성·시각품질 평가 지시
>
> #### 평가 절차
>
> 1. 실제 홈페이지 `https://lifeportfolio.co.kr`를 PC 1440px와 모바일 390px에서 각각 직접 확인합니다.
> 2. 아래 6개 항목을 각 뷰포트에서 각각 0~100점으로 채점하고, 항목별 관찰 근거와 확인 URL을 적습니다.
> 3. 각 뷰포트 점수는 항목 점수에 확정 가중치를 적용해 계산합니다.
> 4. PC 점수와 모바일 점수 가운데 낮은 값을 ⑥축 최종 점수로 채택합니다. 평균은 사용하지 않습니다.
> 5. 확인할 수 없는 항목은 임의 점수로 메우지 말고 **미확인**으로 표시합니다. 미확인 항목이 있으면 ⑥축 최종 점수도 확정하지 말고, 무엇을 추가 확인해야 하는지 적습니다.
>
> #### 채점 항목과 가중치
>
> | 항목 | 가중치 | 평가 지시 |
> |---|---:|---|
> | ① 모바일 적합성 | 25% | 모바일 390px에서 가로 스크롤, 화면 잘림, 겹침, 확대를 강요하는 구성, 뷰포트 이탈, 입력·메뉴 사용 장애가 있는지 실제 화면과 동작으로 확인하십시오. PC 1440px에서는 레이아웃이 과도하게 늘어나거나 비어 보이는지, 주요 콘텐츠의 폭과 정렬이 안정적인지도 확인하십시오. |
> | ② 키보드·보조기술 | 20% | 마우스 없이 Tab·Shift+Tab·Enter·Space·Esc 등으로 핵심 조작이 가능한지, 포커스가 보이고 순서가 논리적인지, 키보드 함정이 없는지 확인하십시오. 이름·역할·상태, 제목 구조, 폼 레이블, 오류 안내, 대체 텍스트 등 보조기술 사용에 필요한 정보가 제공되는지도 관찰 가능한 근거로 평가하십시오. 자동 검사 결과만으로 만점을 부여하지 마십시오. |
> | ③ 텍스트 가독성 | 20% | 본문·버튼·보조문구의 글자 크기, 행간, 줄 길이, 대비, 정보 밀도와 계층이 실제 읽기에 적절한지 확인하십시오. 작은 글씨의 개수만 보지 말고 노출 위치, 중요도, 반복 빈도와 읽기 부담을 함께 판단하십시오. |
> | ④ 터치 타깃 | 15% | 모바일 390px에서 링크·버튼·체크박스·입력 보조 요소를 실제로 조작해 크기와 간격, 인접 요소 오조작 가능성을 확인하십시오. 첨부된 24px·44px 측정값은 참고 근거이며, 예외 적용 여부와 실제 조작성을 별도로 판단하십시오. |
> | ⑤ 핵심 경로 무결성 | 10% | 평가 시점에 공개적으로 접근 가능한 핵심 경로를 시작부터 다음 단계까지 직접 진행하며 끊긴 링크, 진행 불가, 오류 후 복구 불가, 입력 손실, 뒤로 가기 문제 또는 상태 불일치가 있는지 확인하십시오. 로그인·결제 등 실행할 수 없는 단계는 정상으로 가정하지 말고 미확인 범위로 기록하십시오. |
> | ⑥ 시각 일관성 | 10% | 페이지와 뷰포트 사이에서 색상, 타이포그래피, 여백, 정렬, 버튼·카드·아이콘의 형태, 상태 표현과 시각적 위계가 일관되는지 확인하십시오. 취향만으로 평가하지 말고 동일 기능의 표현 불일치와 이해·조작에 미치는 영향을 근거로 제시하십시오. |
>
> #### 계산식
>
> `뷰포트 점수 = 모바일 적합성×0.25 + 키보드·보조기술×0.20 + 텍스트 가독성×0.20 + 터치 타깃×0.15 + 핵심 경로 무결성×0.10 + 시각 일관성×0.10`
>
> `⑥축 최종 점수 = min(PC 1440px 뷰포트 점수, 모바일 390px 뷰포트 점수)`
>
> 각 항목은 PC와 모바일에서 따로 채점하십시오. PC와 모바일의 항목 점수 또는 총점을 먼저 평균 낸 뒤 최종 점수를 만드는 방식은 허용하지 않습니다.
>
> #### 필수 결과 표
>
> | 항목 | 가중치 | PC 1440px 점수 | PC 관찰 근거 | 모바일 390px 점수 | 모바일 관찰 근거 |
> |---|---:|---:|---|---:|---|
> | 모바일 적합성 | 25% |  |  |  |  |
> | 키보드·보조기술 | 20% |  |  |  |  |

>
> - ⑥축 최종 점수: `min(PC ___점, 모바일 ___점) = ___점`
> - 최종 점수를 결정한 낮은 쪽: PC / 모바일

## 3. 신규 삽입문 — 실측 데이터 제시 방식

실측값은 평가자의 관찰을 대체하는 “정답”이나 자체 점수로 제시하지 않고, 출처·조건·한계가 붙은 **참고 증거 묶음**으로 제공한다. 아래 문안을 ⑥축 평가 지시문 다음에 삽입한다.

### 변경 전

> 해당 없음 — 기존 의뢰서에는 ⑥축 실측 자료와 측정 한계 고지가 없습니다.

### 변경 후

> ### 5-2. ⑥축 참고 실측 자료 — 독립 채점을 대체하지 않음
>
> 아래 값은 의뢰자가 보유한 측정 결과입니다. 평가자는 이 값을 참고 자료로 활용하되, 이를 그대로 항목 점수로 환산하거나 의뢰자의 자체 판정을 따르지 마십시오. 실제 사이트 관찰 결과와 함께 검토하고, 측정 조건·표본·예외 규정 때문에 결론을 확정할 수 없는 부분은 별도로 지적해 주십시오.
>
> | 측정 영역 | 제공 실측값 | 평가 시 사용 방법 | 한계 및 주의 |
> |---|---|---|---|
> | WCAG 2.2 2.5.8 AA 최소 타깃 크기 24px | 모바일 208/208 = 100%, PC 210/210 = 100% | 터치 타깃 항목의 참고 자료로 사용하되, 실제 모바일 조작성과 인접 타깃 간격을 직접 확인 | 해당 성공기준의 예외 적용 여부와 측정 절차는 별도 확인이 필요하며, 이 비율만으로 터치 타깃 항목 전체 점수를 확정하지 않음 |
> | WCAG 2.2 2.5.5 AAA 타깃 크기 44px | 모바일 67.3%, PC 64.8% | 더 큰 타깃 기준 충족 현황을 보여 주는 보조 자료로 사용 | AA와 AAA 결과를 혼합하지 않으며, AAA 비율을 AA 미준수로 해석하지 않음 |
> | Core Web Vitals 관련 로컬 Lab 측정 | 6페이지×2뷰포트, CLS 최악 0.0625, LCP 124~3764ms, TBT 전부 0 | 페이지·뷰포트별 편차와 실제 체감에 대한 추가 확인 지점을 정하는 데 사용 | **이 값은 로컬 Lab 환경의 HTTP·실브라우저 측정이며, 실제 사용자 분포를 반영하는 Google 기준의 p75 field 측정값이 아닙니다. 따라서 현장 성능 또는 Core Web Vitals 통과를 확정하는 근거로 사용할 수 없습니다.** |
> | 12px 미만 글씨 | 선언 344건, 고객 노출 212건 | 텍스트 가독성 항목에서 실제 노출 위치·용도·빈도·대비를 확인할 후보 목록으로 사용 | 선언 건수와 고객 노출 건수는 가독성 결함 건수와 동일하지 않음. 실제 화면에서 읽기 부담을 직접 판정해야 함 |
>
> 평가 보고서에는 각 실측값을 **채택**, **부분 채택**, **판단 보류** 중 하나로 표시하고 그 이유를 적어 주십시오. 제공 수치를 다시 인용하는 것만으로 평가 근거를 충족한 것으로 보지 않습니다. 가능하면 실제 화면에서 확인한 사례의 URL·요소·상태를 연결해 주십시오.
>
> 본 의뢰서에 측정 원본, 실행 명령, 측정 시각, 브라우저·운영체제, 페이지별 원시 결과가 함께 제공되지 않았다면 그 항목의 측정 재현 가능성은 **미확인**으로 표시하십시오.

## 4. 신규 삽입문 — 제3자 채점 독립성

아래 문안을 평가 결과 제출 요건 또는 방법론 절에 삽입한다.

### 변경 전

> 해당 없음 — 홈페이지 ⑥축에 관한 독립 채점 제한이 명시되어 있지 않습니다.

### 변경 후

> ### 제3자 독립 채점 원칙
>
> 본 재평가의 점수는 평가자가 제공 자료와 직접 관찰한 증거를 바탕으로 독립적으로 산정해야 합니다. 의뢰자가 보유한 자체 점수, 목표 점수 또는 개선 기대치는 채점 근거가 아니며, 평가자에게 특정 점수나 상승 폭을 요구하지 않습니다.
>
> - 기존 5축의 유효한 비교 기준선은 2차 외부 평가 점수입니다. 3차 점수와 비교할 때 축별 정의와 평가 범위를 바꾸지 마십시오.
> - 신규 ⑥축은 3차에 처음 추가되는 별도 축이므로, 기존 5축의 가중평균에 임의로 합산하거나 1차·2차 대비 상승으로 표현하지 마십시오.
> - 의뢰자가 제공한 ⑥축 자체 점수는 외부 검증값으로 인용하지 말고, 평가자의 점수 산정에도 사용하지 마십시오.
> - 첨부 실측값은 관찰 후보와 보조 증거입니다. 특정 항목의 점수를 자동 결정하는 환산표로 사용하지 마십시오.
> - 점수마다 확인한 근거, 확인하지 못한 범위, 반대 증거와 판단 한계를 함께 제시하십시오.
> - 기존 5축 결과와 신규 ⑥축 결과는 분리해 보고하십시오. 기존 5축 가중평균은 기존 방식대로 산출하고, ⑥축은 PC·모바일 중 낮은 점수를 별도로 병기하십시오.
>
> 권장 결과 표기:
>
> - 기존 5축: ① __ / ② __ / ③ __ / ④ __ / ⑤ __ / 기존 방식 가중평균 __
> - 신규 ⑥축: PC 1440px __ / 모바일 390px __ / 최종 `min(PC, 모바일)` = __
> - ⑥축은 신규 기준선으로 기록하며 기존 5축 평균과 합쳐 하나의 총점으로 만들지 않음

## 5. 반영 위치 요약

1. 기존 §5 제목과 첫 안내문을 **1. §5 평가 대상 문구 대조**의 변경 후 문안으로 교체한다.
2. 그 아래에 **5-1. ⑥ 홈페이지 이용편의성·시각품질 평가 지시**를 삽입한다.
3. 이어서 **5-2. ⑥축 참고 실측 자료 — 독립 채점을 대체하지 않음**을 삽입한다.
4. 결과 제출 요건 또는 방법론 절에 **제3자 독립 채점 원칙**을 삽입한다.
5. 기존 5축의 정의·배점·가중치·비교 기준 문구는 수정하지 않는다.

## 6. 편집 검수 체크리스트

- [ ] 기존 5축의 명칭·정의·평가 범위가 바뀌지 않았는가
- [ ] ⑥축을 기존 5축에 합산하지 않고 별도 결과로 보고하게 했는가
- [ ] PC 1440px와 모바일 390px를 각각 채점하게 했는가
- [ ] ⑥축 최종 점수가 평균이 아니라 두 점수 중 낮은 값인지 명시했는가
- [ ] 실제 사이트 직접 관찰을 요구하면서, 관찰 범위 밖 추측을 금지했는가
- [ ] 확인하지 못한 경로를 임의로 점수화하지 않고 미확인으로 남기게 했는가
- [ ] 로컬 Lab 자료가 p75 field 자료가 아니라는 한계를 굵게 고지했는가
- [ ] 제공 실측값을 자체 점수나 자동 환산 근거로 쓰지 못하게 했는가
- [ ] 제3자가 자체 점수·목표 점수와 독립적으로 채점하도록 했는가
- [ ] ⑥축을 1차·2차 대비 상승으로 표현하지 않고 신규 기준선으로 기록하게 했는가
