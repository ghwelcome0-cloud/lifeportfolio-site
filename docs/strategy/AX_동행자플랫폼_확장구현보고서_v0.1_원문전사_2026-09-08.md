# AX 동행자 플랫폼 확장 구현 보고서 v0.1

## 0. 문서 목적

이 문서는 현재 출시된 인생포트폴리오 리포트와 맞춤 실행 프로그램을 기반으로, 향후 AX 동행자 플랫폼을 다음 단계로 확장하기 위한 공용 기획/구현 문서이다.
최종 목표는 단순 진단 서비스가 아니라,
하나님이 각 사람에게 주신 고유성을 발견하고, 그 고유성을 실제 삶에서 축적 가능한 자산으로 전환하도록 돕는 인생포트폴리오 플랫폼
을 구현하는 것이다.

## 1. 사업의 본질

### 1-1. 한 문장 정의

각 사람의 고유성을 발견하고, 자기이해에서 끝나지 않도록 자기표현·자기설계·자기실행으로 연결하여, 실제 삶에서 축적 가능한 자산을 형성하도록 돕는 플랫폼.

### 1-2. 기존 진단 서비스와의 차이

기존 진단 검사는 대부분 다음 지점에서 멈춘다.
“나는 어떤 사람인가?”
하지만 인생포트폴리오는 다음 흐름까지 이어진다.
자기이해
→ 자기표현
→ 자기설계
→ 자기실행
→ 자산화
→ 현실 문제 해결
→ 검증
→ 거래와 재생산
즉, 사용자를 유형화하는 것이 아니라 고유성을 조명하고, 그 고유성이 실제 삶에서 자산으로 남도록 훈련시키는 서비스다.

### 1-3. 신앙적 세계관

이 서비스의 내부 정체성은 다음 신앙적 세계관에 기반한다.
하나님은 각 사람에게 고유성을 허락하셨다.
인간은 단순한 노동력이 아니라 고유한 사명과 부르심을 가진 존재다.
각자의 고유성이 발견되고 자산화될 때, 창조주의 창조대로 살아갈 수 있다.
그렇게 형성된 자산은 자신만을 위한 것이 아니라 다른 사람을 섬기고 재생산하는 도구가 된다.
궁극적으로 하나님께 영광을 돌리는 삶으로 연결된다.
대표적 성경적 배경:
마태복음 24장 45절: 충성되고 지혜 있는 종의 청지기성
마태복음 28장 18-20절: 재생산과 제자 삼는 지상명령
다만 외부 일반 시장에서는 다음과 같이 표현할 수 있다.

| 내부 표현 | 외부 표현 |
|---|---|
| 하나님이 주신 고유성 | 개인의 고유성 |
| 사명과 부르심 | 삶의 방향성과 역할 |
| 청지기적 자산 형성 | 자기다운 자산 형성 |
| 하나님께 영광 | 의미 있는 기여와 재생산 |
| 지상명령 | 영향력의 확장과 다음 세대 전수 |

## 2. 전체 서비스 확장 구조

최종 서비스는 다음 단계로 확장된다.
고유성 진단
→ 인생포트폴리오 리포트
→ 자산 유형/자산화 루트 추천
→ 맞춤형 자산화 실행 프로그램
→ 인생 훈련 게임 / 자산화 시뮬레이션
→ 자산 유형별 소그룹 커뮤니티
→ 미네르바 대학형 현실 문제 해결 프로젝트
→ 자산 카드 등록·검증
→ 자산 거래·협업·수익화 플랫폼

## 5. 핵심 개념 정의

### 5-1. 고유성

고유성은 사람을 몇 가지 유형으로 묶는 분류값이 아니다.
각 사람의 가치, 강점, 관심, 실행 방식, 사명, 환경, 리듬, 선택 기준이 결합된 고유한 조합이다.

### 5-2. 자산

본 플랫폼에서 자산은 다음 특징을 가진다.
미래 수익성
앞으로 경제적·관계적·사회적·사역적 가치를 만들 가능성이 있다.
축적성
한 번의 행동으로 사라지지 않고 기록, 산출물, 신뢰, 역량으로 쌓인다.
통제 가능성
외부 환경에만 의존하지 않고 사용자가 직접 성장·관리·활용할 수 있다.
재사용성
한 번 만든 결과물이 다음 실행, 교육, 거래, 협업에 다시 쓰일 수 있다.
검증 가능성
단순 주장이나 자기 느낌이 아니라 산출물, 피드백, 사용 기록, 거래 기록으로 확인 가능하다.

### 5-3. 자산화

자산화란 사용자의 고유성을 다음과 같이 전환하는 과정이다.
내 안의 고유성
→ 표현 가능한 언어
→ 설계 가능한 방향
→ 실행 가능한 과제
→ 남길 수 있는 산출물
→ 검증 가능한 자산
→ 거래·협업·재생산 가능한 가치

## 6. 자산 유형 체계

초기 자산 유형은 6개로 설계한다.
단, 이 자산 유형은 사람을 분류하는 용도가 아니다.
“당신은 OOO형 인간입니다”가 아니라,
“현재 당신의 고유성을 자산화하기에 적합한 시작 루트는 OOO 자산입니다.”

### 6-1. 자산 유형 6개

| 자산 유형 | 설명 | 대표 산출물 |
|---|---|---|
| 지적 자산 | 지식, 통찰, 연구, 프레임워크를 축적하는 자산 | 글, 책, 강의안, 커리큘럼, 방법론 |
| 콘텐츠·표현 자산 | 생각, 메시지, 브랜드를 외부로 표현하는 자산 | SNS, 영상, 뉴스레터, 발표, 브랜드 메시지 |
| 경험·프로젝트 자산 | 실제 실행 경험과 문제 해결 사례를 축적하는 자산 | 프로젝트 사례, 실험 기록, 포트폴리오 |
| 관계·공동체 자산 | 신뢰, 네트워크, 커뮤니티를 축적하는 자산 | 모임, 커뮤니티, 파트너십, 멘토링 관계 |
| 시스템·사업 자산 | 반복 가능한 구조, 상품, 프로세스, 서비스를 만드는 자산 | 서비스, 상품, 매뉴얼, 체크리스트, 자동화 시스템 |
| 금융·관리 자산 | 돈, 시간, 자원, 현금흐름을 관리하고 증식하는 자산 | 예산표, 수익 모델, 현금흐름표, 자원 배분 원칙 |

### 6-2. 영성·사명 자산의 위치

영성·사명 자산은 별도 거래형 자산으로 다루기보다, 모든 자산 유형을 정렬하는 상위 기준으로 둔다.
즉,
“무엇을 쌓을 것인가?”보다 먼저
“이 자산은 나의 사명과 어떻게 연결되는가?”를 묻는다.

사람은 루트보다 크며, 자산 루트는 삶의 변화에 따라 확장될 수 있습니다.

## 8. 김영식님 샘플 적용 결과

첨부된 리포트 기준, 김영식님의 자산화 루트는 다음과 같이 제안된다.

### 8-1. 최종 추천 문장

현재 당신의 고유성을 자산화하기에 가장 적합한 시작 루트는
시스템·사업 자산입니다.
당신은 신념과 원칙을 기준으로 얽힌 문제를 풀고,
그 해결 과정을 반복 가능한 실행 구조로 남길 때
가장 빠르게 자산화됩니다.
이 루트는 당신을 유형으로 묶는 이름이 아니라,
당신의 고유성을 실제 삶에서 자산으로 전환하기 위한
현재의 시작 경로입니다.

### 8-2. 자산화 한 줄 요약

신념과 원칙을 기준으로 얽힌 문제를 풀어,
사람과 조직이 다시 사용할 수 있는 실행 시스템으로 남기는 사람.

### 8-3. 자산화 스택

| 구분 | 자산 유형 | 역할 |
|---|---|---|
| 기반 자산 | 지적 자산 | 신념, 원칙, 문제해결 프레임워크 정리 |
| 시작 루트 | 시스템·사업 자산 | 반복 가능한 실행 구조와 서비스로 전환 |
| 표현 자산 | 콘텐츠·표현 자산 | 글, 강의, 리포트, 브랜드 메시지로 전달 |
| 확장 자산 | 관계·공동체 자산 | 소그룹, 코칭, 멘토링, 커뮤니티로 확장 |
| 관리 자산 | 금융·관리 자산 | 수익 모델, 가격, 현금흐름, 사업 운영으로 정리 |

## 11. 인생 훈련 게임

### 11-1. 개념

인생 훈련 게임은 사용자가 자신의 인생포트폴리오 리포트를 바탕으로, 자산화 루트를 따라 퀘스트를 수행하고 레벨업하며 실제 자산을 형성하도록 돕는 시뮬레이션 서비스다.
거대한 3D 게임이 아니어도 된다.
초기에는 레트로 게임 수준의 UI여도 충분하다.
핵심은 그래픽이 아니라 다음 구조다.
리포트
→ 캐릭터 생성
→ 자산 루트 선택
→ 퀘스트 수행
→ 증거 제출
→ 피드백
→ 경험치 획득
→ 레벨업
→ 자산 카드 등록

진단 응답 데이터
리포트 생성 결과

동료 피드백

현실 프로젝트 성과
자산 카드 검증 단계
거래/협업/수익화 기록
핵심 데이터 질문:
어떤 고유성을 가진 사람이 어떤 자산 루트를 선택했을 때 실제 성과가 나는가?
이 데이터가 쌓이면 강력한 진입장벽이 된다.

### 17-4. 재현성 원칙

같은 응답은 언제나 같은 결과로 재현된다.

AI 문장은 생성 후 저장하여 동일 결과로 재사용한다.
버전 번호를 기록한다.
리포트/프로그램 생성 시 사용된 룰북 버전을 저장한다.

## 20. AI 에이전트 구성

향후 플랫폼에는 여러 AI 에이전트를 붙일 수 있다.

### 20-1. Report Curator Agent

역할:
리포트 문장 정합성 확인
사명/비전/강점 간 충돌 확인
표현 톤 유지
금지:
응답에 없는 내용을 단정하지 않음
사람을 유형화하지 않음

### 20-2. Asset Route Agent

역할:
자산화 루트 추천
기반/확장/보완 자산 제안
첫 산출물 제안
필수 문구:
이 자산 루트는 당신을 하나의 유형으로 묶기 위한 이름이 아닙니다.
당신의 고유성을 실제 삶에서 자산으로 전환하기 위한 현재의 시작 경로입니다.

### 20-3. Quest Master Agent

역할:
사용자의 자산 루트에 맞는 일일/주간 퀘스트 제공
난이도 조절
완료 기준 제시
출력 형식:
오늘의 퀘스트
완료 기준
예상 소요 시간
제출할 증거
다음 단계

### 20-4. Execution Coach Agent

역할:
사용자가 막혔을 때 회복 질문 제공
실행을 작은 단위로 쪼개기
다음 한 걸음 제안

### 20-5. Evidence Evaluator Agent

역할:
제출된 산출물이 완료 기준을 충족하는지 1차 평가
피드백 생성
검증 단계 추천
주의:
최종 인증자는 사람 또는 운영진으로 둘 수 있음

### 20-6. Community Facilitator Agent

역할:
소그룹 대화 촉진
주간 회고 질문 제공
참여 저하 사용자 알림
멘토에게 이슈 전달

### 20-7. Project Matcher Agent

역할:
현실 문제와 사용자 자산 유형 매칭
팀 구성 추천
역할 배정안 생성

### 20-8. Asset Card Generator Agent

역할:
퀘스트 결과물을 자산 카드로 정리
산출물/피드백/검증 기록 연결
다음 확장 방향 제안

## 24. 주요 리스크와 대응

### 24-1. 유형화 리스크

문제:
사용자가 자산 유형을 정체성 유형으로 오해할 수 있음
대응:
“자산 유형”이 아니라 “자산화 시작 루트”라고 표현
사람은 루트보다 크다는 문구 삽입
회차별 변화 가능성 강조

### 24-2. 실행 이탈 리스크

문제:
리포트는 구매하지만 실행하지 않을 수 있음
대응:
10분 첫 행동 제공
7일 미니 퀘스트
동료 인증
레벨업 보상
소그룹 연결

### 24-3. 플랫폼 과개발 리스크

문제:
처음부터 거대한 게임/플랫폼을 개발하면 비용 부담이 큼
대응:
노션/웹 대시보드/카카오톡/구글폼 수준으로 베타 운영
검증 후 자동화
레트로 게임 UI로 시작

### 24-4. AI 환각 리스크

문제:
AI가 응답에 없는 내용을 만들어낼 수 있음
대응:
핵심 판단은 규칙 기반
AI는 문장화/피드백 보조로 제한
출력 근거 문항 기록
버전 관리
사용자 확인 절차

### 24-5. 개인정보/민감정보 리스크

문제:
진단 응답, 신앙, 사명, 진로 정보는 민감할 수 있음
대응:
명시적 동의

제3자 제공 금지 원칙

## 27. 최종 결론

AX 동행자 플랫폼의 궁극적 방향은 다음과 같다.
인생포트폴리오 리포트는 끝이 아니라 시작이다.
리포트는 사용자의 고유성을 발견하는 캐릭터 생성 단계이고,
자산화 루트는 그 고유성이 현실에서 어떤 자산으로 전환될 수 있는지 알려주는 시작 경로다.
맞춤형 자산화 실행 프로그램은 그 경로를 따라 산출물을 만들게 하는 훈련 과정이며,
인생 훈련 게임은 그 과정을 지속하게 만드는 시뮬레이션 장치다.
소그룹 커뮤니티와 현실 문제 해결 프로젝트는 훈련을 실제 삶으로 연결하고,
자산 카드는 그 결과를 검증 가능한 자산으로 축적한다.
따라서 최종 플랫폼은 단순 진단 서비스가 아니라,
고유성 발견 플랫폼
+ 자산화 훈련소
+ 인생 훈련 게임
+ 평생교육 프로그램
+ 현실 문제 해결 랩
+ 자산 장부
+ 협업·거래 플랫폼
이 결합된 구조가 되어야 한다.
대표님의 사업 본질을 가장 정확히 담은 최종 문장은 다음이다.
하나님이 각 사람에게 주신 고유성을 발견하고, 그 고유성을 실제 삶에서 축적 가능한 자산으로 전환하도록 돕는 인생포트폴리오 플랫폼.
이 문장을 모든 기획, 개발, 디자인, AI 에이전트 설계의 최상위 기준으로 삼으면 된다.
