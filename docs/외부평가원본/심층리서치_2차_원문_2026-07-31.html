✅ 검증된 개선 (지면에서 확인)

  1. 미다듬 표기 해소 — §5 지면에서 영문 내부 키(typeLine, coreOneLine 등) 0건, "매우 그렇다" 원응답 노출 0건, 조사 비문 0건 확인. 강점 키워드가 "여유 있는 호흡 위에 세워진 분석적 통찰" 등 정제된 문장으로 교체됨.
  2. 사명·비전 문장 단축 — 사명 "사람을 돌보는 손길로 어제보다 더 자라게 한다"(약 20자, 1차 44.1자 대비 절반 이하), 비전 "넘어져도 다시 서는 뚝심으로 또렷이 사람이 함께 자라는 세상을 만든다"(약 33자, 1차 55.8자 대비 단축). 첫 읽기 이해도 실질 향상.
  3. IX·X장 신설로 근거 투명성 확보 — IX장 "이 리포트는 이렇게 만들어졌습니다"에서 응답→산출 3단계 공개 + Q13·Q39·Q41·Q47·Q49·Q73 문항 번호와 원응답 공개. X장에서 38/38, 200/200, 10^58 재현성 데이터 지면 명시. 벤치마크 대부분이 하지 않는 수준의 투명성.

⚠️ 미검증 주장 (지면 또는 외부에서 확인 불가)

  1. "프로그램 지면 반복 6종 120/120 → 0/120" — 프로그램 내부 반복은 감소한 것으로 보이나, 진단 리포트와 실행 프로그램 간 동일 완료 기준 문장 반복은 여전히 존재("흩어져 있던 것이 한 화면에 모여 있습니다" 등 3개 완료 기준 문장이 양 리포트 합쳐 각각 ~5회 반복). 0/120은 프로그램 단독 측정치로 추정.
  2. "표본 200명 지문 충돌 0/200" — 자체 실측치이며 외부 감사를 받지 않았음(의뢰 프롬프트 §1에 명시). 200명 표본의 구성 기준(층화, 모집단)도 미공개. 마케팅에 인용 시 "자체 실측" 명시 필수.
  3. "4축 카드 본질 문장 고유성 39/39/39/38" — 단일 샘플(1인분)에서는 다수 샘플 비교가 불가하므로 확인 불가. 엔진 결정론성을 고려하면 plausible하나, 외부 검증 없음.

🔴 여전히 치명적 약점

  1. ⑤ 전문성·신뢰감 67점 (벤치마크 평균 ~75 하회) — 규준·신뢰도·구성타당도 연구 전무. "당신의 자기이해 75%는 무엇에 대한 75%인가?" 질문에 답할 수 없음. 기업 HR·교육기관 도입 시 최대 장벽. 단, 1차 58점 대비 +9점 상승은 IX·X장 신설과 정직한 고지의 효과.
  2. ① 첫인상 직관성 73점 (16Personalities 92점 대비 -19점) — 잔존 추상 표현 6곳 확인: "작품을 흐르게 해 아름다움으로 세우는 자리에서"(II장), "빛나는 것을 밝혀 주는 사람"(I장) 등. 유형 라벨 부재(의도적)로 기억·공유 앵커 약함.
  3. 재현성 100% ≠ 재검사 신뢰도 — 엔진 결정론성(같은 입력→같은 출력)은 확인되나, "같은 사람이 다시 검사하면 같은 결과가 나오는가?"(재검사 신뢰도)는 전혀 별개의 질문. 후자에 대한 연구 없음. 마케팅에서 혼용 시 허위.

판정: 부분 해소. 측정 방식·문항 매핑·재현성 데이터를 지면에 공개한 것은 벤치마크 대부분(Gallup, MBTI, DISC 등)이 하지 않는 수준의 투명성. 그러나 규준·신뢰도·타당도 연구 부재는 1차와 동일. ⑤축 58→67점 상승 원인: (a) 산출물 변화(IX·X장 신설), (b) 평가 방법론 변화(§6-2 대체 채점표 적용—N/A 항목을 0점이 아닌 평가 유보로 처리).

C등급: 사용 금지 (과장 또는 허위)

근거 없거나, 혼용·과장·허위가 되는 문장.

  1. [C] "심리검사입니다." — 사용 금지. 규준·신뢰도·타당도 연구가 없으므로 심리검사가 아님. "자기이해·자기설계 진단 서비스"로 표기.
  2. [C] "타당도가 검증되었습니다." — 사용 금지. 구성타당도·예측타당도 연구 전무. 내용타당도 매핑 문서도 외부 공개 안 됨.
  3. [C] "세계 최고 / 세계 1위 / 세계 유일" — 사용 금지. "완료 판정 기준을 지면에 명시한 소비자용 진단" 범주에서 경쟁자가 확인되지 않았으나, 이것이 "세계 유일"을 의미하지 않음—조사 범위 밖 제품이 존재할 수 있음. "조사한 제품 중"으로 한정 시 B등급.
  4. [C] "AI가 분석합니다." — 사용 금지. 엔진은 LLM이 아닌 규칙 기반. "AI"를 광의로 해석하더라도 오인 소지 큼.
  5. [C] "정확도 O%입니다." — 사용 금지. "정확도"의 기준(무엇에 대한 정확도?)이 정의되지 않음. 규준이 없으므로 정확도 개념 자체가 적용 불가.
  6. [C] "과학적 근거에 기반합니다." — 사용 금지. 심리측정학적 근거(규준·신뢰도·타당도)가 없으므로 "과학적" 표현은 과장. "응답 데이터 기반"은 사용 가능.
  7. [C] "신뢰도 100% / 신뢰도가 높습니다." — 사용 금지. 엔진 재현성(결정론성) ≠ 재검사 신뢰도. "재현성 100%"는 사용 가능(A/B), "신뢰도 100%"는 허위.
  8. [C] "고유성 80억 분의 1" — 사용 금지. 10^58 조합이 있다는 것과 "80억 분의 1"은 다른 주장. 10^58 ≫ 80억(8×10^9). 후자는 전 세계 인구 기준이나, 10^58 조합과 80억 인구의 관계를 단순 나눗셈으로 표현하면 오인 소지. "10^58 가능 조합"으로 표기(B등급).
  9. [C] "개인 맞춤 정밀 진단" — 사용 금지. "정밀"은 규준·신뢰도·타당도가 뒷받침되어야 하는 표현. "응답 기반 맞춤"으로 한정 시 B등급.
  10. [C] "검증된 재현성" — 사용 금지. "검증"은 외부 감사를 의미. 자체 실측은 "검증"이 아님. "자체 실측 재현성"으로 표기(B등급).
  11. [C] "심리학적으로 설계되었습니다." — 사용 금지. 심리학 이론 기반은 주장 가능하나, 심리측정학적 검증이 없으므로 "심리학적으로"는 오인 소지. "응답 데이터 기반으로 설계"로 한정.

9.3 심리측정 관점 한계 고지문 초안 (지면·마케팅에 그대로 사용 가능)

지면용 한계 고지문 (§5 IX장 또는 별도 페이지에 삽입 가능)

"이 리포트는 규준 기반 심리검사가 아닙니다. 규준 표본·내적 일관성(Cronbach's α)·재검사 신뢰도·구성타당도 연구가 아직 없습니다. 이 리포트는 56문항 응답을 결정론적 규칙 기반 엔진으로 분석하여, 개인 맞춤 문장과 실행 가이드를 자동 생성하는 자기이해·자기설계 진단 서비스입니다. 지수는 해당 영역 문항 응답의 가중 합산이며, 규준 집단 대비 상대적 위치가 아닙니다. 같은 응답으로 다시 만들면 언제나 같은 리포트가 나옵니다(재현성 100%). 이것은 엔진의 결정론성이지, 재검사 신뢰도(같은 사람이 다시 검사할 때 같은 결과가 나오는 정도)가 아닙니다. 현재 임상·실증 연구를 수행할 만큼 유료 응답자 트래픽이 축적되지 않은 단계이며, 트래픽이 축적되는 대로 순차적으로 신뢰도·타당도 연구를 수행할 예정입니다."

마케팅용 짧은 버전 (웹사이트·소개 페이지용)

"인생포트폴리오는 규준 기반 심리검사가 아닌, 결정론적 규칙 기반 자기이해·자기설계 진단 서비스입니다. 같은 응답 → 항상 같은 결과(재현성 100%). 규준·신뢰도·타당도 연구는 데이터 축적 단계입니다."

9.4 "재현성 vs 신뢰도" 용어 사용 지침

★ 이 두 용어를 섞어 말하면 허위가 되는 지점 — 문장 단위 경고

표현판정이유
"재현성 100%"A (사용 가능)엔진 결정론성(같은 입력 → 같은 출력)은 §5 IX장에 근거 있음. 소프트웨어 결정론의 사실적 표현.
"재현성 100%(같은 응답 → 항상 같은 결과)"A (사용 가능)괄호 안 설명 추가로 소비자 오인 방지. 권장 형태.
"신뢰도 100%"C (사용 금지·허위)재검사 신뢰도 연구가 없으므로 허위. "신뢰도"는 심리측정학에서 "같은 사람이 다시 검사할 때 같은 결과가 나오는 정도"를 의미. 이것은 측정하지 않았음.
"신뢰도가 높습니다"C (사용 금지·허위)동일. 재검사 신뢰도 데이터 없음.
"재현성 100%로 신뢰할 수 있습니다"C (사용 금지)"재현성"과 "신뢰"를 같은 문장에서 연결하면 소비자가 "재검사 신뢰도"로 오인. "재현성 100%"로 끝내고 "신뢰" 용어는 분리.
"재현성이 높다는 것은 신뢰할 수 있다는 뜻입니다"C (사용 금지)재현성(엔진 결정론) ≠ 재검사 신뢰도(응답 안정성). 두 개념을 동일시하는 설명은 허위.
"같은 응답 → 항상 같은 결과(엔진 재현성). 단, 재검사 신뢰도(같은 사람이 다시 검사할 때 같은 결과)는 별개의 개념이며, 현재 연구 중입니다."A (사용 가능·권장)두 개념을 명확히 분리하고, 후자의 부재를 정직하게 고지. 마케팅에서 가장 안전한 표현.
"재현성 100%는 엔진의 결정론성이며, 심리측정학의 재검사 신뢰도와는 다릅니다."A (사용 가능·권장)전문가 대면·기업 제안서용. 두 개념의 구분을 명시적으로 선언.

★ 핵심 경고: 혼용이 허위가 되는 정확한 지점

"재현성 100%" 자체는 사실(A등급). 그러나 이 말 직후에 "신뢰도"·"신뢰할 수 있다"·"정확하다"·"검증되었다" 등의 용어가 같은 문단에서 사용되면, 소비자는 "재검사 신뢰도가 100%"로 오인. 이 오인이 발생하는 지점에서 허위 광고가 성립. 따라서: ① "재현성"과 "신뢰도"는 같은 문단에 함께 두지 않을 것. ② 부득이 함께 둘 경우, 위 표의 마지막 두 행(A등급) 형태로 명시적 분리 선언을 삽입할 것. ③ "신뢰도" 용어는 재검사 신뢰도 연구가 완료될 때까지 마케팅에서 사용 금지.
