# 인생포트폴리오 마케팅 영상 제작 규칙 v1.0

> 적용 범위: YouTube 롱폼·Shorts, Instagram Reels, 광고·브랜드 영상  
> 목적: 고객이 재생 결함 없이 내용을 이해하고, 신뢰를 잃지 않은 채 리포트 샘플·홈페이지의 다음 행동으로 이동하게 한다.

## 1. 전략 커널

### 진단
부분 패치, 자동 점수, 화려한 효과는 실제 시청에서 발생하는 잘린 음성·오탈자·물체 점프를 보장하지 못한다.

### 지도 원칙
1. **무결점 재생이 고급 연출보다 먼저다.**
2. AI는 공간·재질·빛·카메라에 쓰고, 한글·숫자·논리 관계는 결정론적 벡터로 보호한다.
3. 승인 판단은 사람이 전체 영상을 1× 정상속도로 보고 들은 결과가 자동 지표보다 우선한다.

### 일관된 행동
- 단일 VO 테이크, 폰트 렌더링 텍스트, 전체 playout QA를 기본 파이프라인으로 사용한다.
- 결함이 하나라도 재현되면 배포를 차단하고, 같은 구조의 모든 장면을 함께 교체한다.
- 제작 성과는 자산 수가 아니라 이해·신뢰·다음 행동의 마찰 감소로 본다.

## 2. 시각 제작 파이프라인

### 2.1 전체→해부→원리→회수
모든 핵심 시퀀스는 다음 의미 순서를 갖는다.
1. **전체**: 첫 화면에서 구조와 질문을 보여준다.
2. **Cutaway**: 핵심 레이어를 분리한다.
3. **Deep zoom**: 한 원리·행동으로 들어간다.
4. **회수**: 분해한 요소를 전체 구조로 다시 연결한다.

빠른 컷 수보다 VO·포인터·레이어 동기가 중요하다. 의미 없는 flash, glow, zoom, whoosh는 삭제한다.

### 2.2 AI와 결정론적 합성의 경계
| AI 사용 허용 | 결정론적 제작 필수 |
|---|---|
| 배경 공간, 재질, 조명, 카메라 이동, 텍스트 없는 추상 3D 오브젝트 | 한글, 숫자, 포인터, 카드 관계, 경로, CTA, 개인정보 마스킹 |

- AI가 사람·손·펜·읽어야 하는 텍스트를 생성하지 않는다.
- AI plate 위에 폰트·벡터 정보 레이어를 합성하고 tracking한다.
- 텍스트가 있는 장면은 2× 이상 supersampling 후 Lanczos로 납품 해상도에 다운샘플한다.

### 2.3 그래픽 무결성
- 한글 원문 manifest와 화면 문자열이 byte-exact로 일치해야 한다.
- 자소 변형, 한 프레임 flicker, popup, 물체 morph·소실·jump는 1건도 허용하지 않는다.
- 라벨은 `label_id`, `target_layer`, 좌표, in/out frame을 기록한다.
- 포인터는 target을 놓치거나 다른 레이어와 교차하지 않는다.

## 3. 오디오 규칙

- 편당 VO는 한 번에 읽는 **단일 연속 take**를 원칙으로 한다.
- 문장 조각 이어붙이기, 대본 외 광고·CTA, 음성 중복을 금지한다.
- 일반 문장 간격은 0.35–0.65초. 2초 이상 공백은 화면 질문·행동·음악 cadence가 있는 의도된 구간만 허용한다.
- click/pop, 잘린 호흡·음절, 룸톤·음색·속도 jump, BGM pump·phrase cut, Foley 선행·지연이 없어야 한다.
- 권장 master: -17~-15 LUFS, true peak ≤ -1.0 dBTP, clipping 0.
- whoosh/click은 실제 사건과 30fps 기준 ±2프레임 안에 동기한다.

## 4. 포맷별 필수 규칙

### 롱폼
- 전체 러닝타임 동안 설명·실습·회수가 이어져야 한다.
- 마지막 발화 후 end hold는 8–12초를 기본으로 한다.
- PDF·리포트는 redacted·flattened 파생본만 사용하며 페이지/VO anchor를 맞춘다.

### Shorts·Reels
- 1080×1920, 30fps, 32–40초 권장.
- 1초 안에 질문·문제·행동 중 하나가 이해돼야 한다.
- safe area: 좌우 90px, 상단 220px, 하단 360px, 우측 UI 180px 안쪽에 핵심 정보를 두지 않는다.
- 자막은 최대 2줄, CPS 15 이하, overlap·역전 0.
- 한 편에 Hook 1, Action 1, CTA 1만 둔다.

## 5. 방송 Playout QA

1. 정본을 처음부터 끝까지 1× 정상속도로 한 번 보고 듣는다.
2. 의심 구간을 앞뒤 3초 포함해 정상속도로 반복한다.
3. 자동 OCR·ASR·파형은 후보 탐지용이며 승인 대체가 아니다.
4. 다음 중 하나라도 실제 재현되면 P0로 배포를 차단한다.
   - 음절·호흡 잘림, click/pop, 중복·겹침, 룸톤·음색 jump
   - 한글 오탈자·flicker, 화면/VO/자막 불일치
   - 손·사람·물체 morph·jump
   - 오류로 느껴지는 freeze·검은 프레임·decode 이상
   - BGM/Foley 불연속 또는 VO masking
   - 개인정보·비마스킹 리포트·금지 주장

## 6. 제출 증거

- master, VO, BGM, Foley, SRT, WebVTT와 SHA-256
- 대본 SSOT, cue/timemap, intentional pause 목록
- 텍스트 manifest, 폰트, vector 원본, layer/label/camera map
- AI plate와 결정론적 overlay의 역할 분리 설명
- loudness, rights, redaction, 변경/비변경 diff
- 사람 playout 결과와 실제 타임코드

## 7. 승인 상태 용어

- **검토 후보**: 제작자가 볼 수 있으나 게시 불가.
- **방송 송출 기본 QC 통과**: 전체 사람 playout에서 P0=0.
- **게시 승인**: URL/UTM, 플랫폼 자막·모바일 렌더, 결제→리포트 E2E까지 출시 QA 완료 후 별도로 부여.

## 8. 참고 편집 문법

- 건축해부식 교육 영상에서 **전체→단면→deep zoom→회수**, parallax, tracked pointer, event-synced sound 문법을 참고한다.
- 참고작의 내용·그래픽·카피는 복제하지 않는다. 인생포트폴리오의 발견→살아냄→남김 구조와 Warm Editorial 팔레트로 재설계한다.
