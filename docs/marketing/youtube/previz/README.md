# 프리비즈 참조 구현 (제14조 ⑭항)

## 이게 무엇인가
**색상 코딩 3D 프리비즈**를 만드는 최소 재현 스크립트입니다.
여기서 나온 mp4 를 AI 생성기에 `@Video1` **구조 레퍼런스**로 넣으면,
3D 가 계산한 원근/패럴랙스를 유지한 채 질감만 실사로 바뀝니다.

기법 전문과 근거는 `../71_HYBRID_3D_PRODUCTION_RULES.md` **§11 (제14조 ⑬⑭항)** 을 보십시오.

## 왜 이 파일을 저장소에 넣었는가
프리비즈 렌더 설정은 **한 줄만 틀려도 52배 느려집니다**(교훈 161).
그래서 "설명"이 아니라 **돌아가는 코드**를 정본으로 남깁니다.

## 실행
```bash
pip install bpy                     # bpy 5.2.0 확인됨. torch/GPU 불필요
mkdir -p _pv3
python3 -u previz_reference.py      # 72프레임, 약 14초
ffmpeg -y -framerate 24 -i _pv3/h_%04d.png \
       -c:v libx264 -preset veryfast -crf 16 -pix_fmt yuv420p previz.mp4
```

## 이 스크립트가 지키는 것 (건드리기 전에 읽으십시오)
| 항목 | 값 | 근거 |
|---|---|---|
| `samples` | **1** | 발광 원색은 광선 추적 불필요. 8 로 올리면 52배 느려집니다 |
| `max_bounces` | **0** | 반사·굴절 없음 |
| `use_denoising` | **False** | 노이즈가 없으므로 불필요 |
| 해상도 | **832x468** | 구조 레퍼런스이므로 고해상도가 필요 없습니다 |
| 세트 크기 | 바닥 16x12m, 벽 3면 h=4.4m | 카메라가 배경 밖을 보면 검은 구멍이 생깁니다 (⑭-4) |
| 도형 | cube / cylinder 만 | 디테일 모델링은 AI 실사 생성과 간섭합니다 (⑭-2 규칙 1) |
| 색 | 마젠타/시안/옐로/레드 원색 | 색이 역할입니다. 겹치면 AI 가 합쳐버립니다 (⑭-2 규칙 2·3) |
| `hold_frac` | 마커는 u<0.40 까지 정지 | 대표님 지시 "정지 구간이 없어요" (⑬) |
| `arc_deg` | 104도 | 55도 미달이면 켄번즈 확대와 구분되지 않습니다 |

## 이 장면이 표현하는 것
대표님 지시(CEO-51) 원문:

> "세 프로젝트 문서에서 같은 역할 단어만 붉게 떠올라 한 곳으로 모이는 것이
> 화면에서 실제로 일어나야 했네요."

- 마젠타 / 시안 / 옐로 평면 = 세 프로젝트 문서
- 붉은 작은 블록 3개 = 세 문서에 **반복되는 같은 역할 키워드**
- 전반 40% = 마커가 문서 위에 **정지** (관객이 세 문서를 읽을 시간)
- 후반 60% = 세 마커가 **떠올라 한 점으로 수렴**
- 카메라 = 좌→우 104도 스윕 + 하강 (문서들의 원근이 계속 변함 = 컷 내부 모션)

## 프롬프트 골격
`../71_HYBRID_3D_PRODUCTION_RULES.md` **§11 ⑭-5** 에 그대로 쓸 수 있는 골격이 있습니다.
필수 4요소를 빠뜨리지 마십시오 — 하나만 빠져도 AI 가 프리비즈를 구조로 읽지 않습니다.
