# 프리비즈 참조 구현 (제14조 ⑭항)

## 이게 무엇인가
**색상 코딩 3D 프리비즈**를 만드는 최소 재현 스크립트입니다.
여기서 나온 mp4 를 AI 생성기에 `@Video1` **구조 레퍼런스**로 넣으면,
3D 가 계산한 원근/패럴랙스를 유지한 채 질감만 실사로 바뀝니다.

기법 전문과 근거는 `../71_HYBRID_3D_PRODUCTION_RULES.md` **§11 (제14조 ⑬⑭항)** 을 보십시오.

## 왜 이 파일을 저장소에 넣었는가
프리비즈 렌더 설정은 **한 줄만 틀려도 52배 느려집니다**(교훈 161).
그래서 "설명"이 아니라 **돌아가는 코드**를 정본으로 남깁니다.

## 파일
| 파일 | 역할 |
|---|---|
| `previz_reference.py` | 프리비즈 렌더 참조 구현 (**v5** · 한글 알파 텍스처 반영본) |
| `marker_word_alpha.png` | 강조어 마커 텍스처. **RGBA · 배경 알파 0** · 512x256 |

## 실행
```bash
pip install bpy                     # bpy 5.2.0 확인됨. torch/GPU 불필요
python3 -u previz_reference.py      # 72프레임, 약 14.6초. 출력은 ./_out/
ffmpeg -y -framerate 24 -i _out/m_%04d.png \
       -c:v libx264 -preset veryfast -crf 16 -pix_fmt yuv420p previz.mp4
```
출력 경로는 환경변수 `PREVIZ_OUT` 으로 바꿀 수 있습니다.
경로는 **이 파일 위치 기준으로 자동 해석**되므로 어디에 두고 실행해도 됩니다.

**실행 검증 (2026-08-22, 이 저장소 사본으로 직접 실행):**
`PREVIZ5 72 frames  14.6s  (0.202 s/frame)  setup 0.2s`

## 이 스크립트가 지키는 것 (건드리기 전에 읽으십시오)
| 항목 | 값 | 근거 |
|---|---|---|
| `samples` | **1** | 발광 원색은 광선 추적 불필요. 8 로 올리면 52배 느려집니다 |
| `max_bounces` | **0** | 반사·굴절 없음 |
| `use_denoising` | **False** | 노이즈가 없으므로 불필요 |
| 해상도 | **832x468** | 구조 레퍼런스이므로 고해상도가 필요 없습니다 |
| 세트 크기 | 바닥 16x12m, 벽 3면 h=4.4m | 카메라가 배경 밖을 보면 검은 구멍이 생깁니다 (⑭-4 · 교훈 163) |
| 도형 | cube / cylinder / plane 만 | 디테일 모델링은 AI 실사 생성과 간섭합니다 (⑭-2 규칙 1) |
| 색 | 마젠타/시안/옐로/레드 원색 | 색이 역할입니다. 겹치면 AI 가 합쳐버립니다 (⑭-2 규칙 2·3) |
| `hold_frac` | 마커는 u<0.40 까지 정지 | 대표님 지시 "정지 구간이 없어요" (⑬) |
| `arc_deg` | 104도 | 55도 미달이면 켄번즈 확대와 구분되지 않습니다 |

## v5 에서 바뀐 것 — 글자 통제 (⑭-7 · 교훈 165)
v3 까지는 강조어 마커가 **빈 붉은 큐브**였고, 그 결과 AI 가 글자 내용을 임의로 채워
**오철자 영문(`Report` / `Renes`)** 이 나왔습니다.

| 항목 | 값 | 근거 |
|---|---|---|
| 마커 형상 | 큐브 아님 · **텍스처 plane** | 글자 자체를 **구조**로 전달해야 통제됩니다 |
| 텍스처 PNG | **RGBA · 배경 알파 0** | 불투명이면 화면에 **검은 카드**가 나타납니다 (v4 실측) |
| 머티리얼 | `TexImage.Alpha → MixShader.Fac` + `blend_method='BLEND'` | 알파가 믹스를 구동해야 배경이 사라집니다 |
| 보간 | `interpolation='Closest'` | 글자 경계를 뭉개지 않습니다 |
| z 오프셋 | **>= +0.032** | +0.012 는 문서에 파묻힙니다 |
| 부상 회전 | `rotation_euler = (v*1.15, 0, 0)` | 누우면 카메라에서 안 읽힙니다 |

**결과.** BEFORE `Report`/`Renes` → AFTER **「조율자」**. 렌더 속도는 0.195 → 0.202~0.207 s/frame 으로 사실상 불변.

> ⚠ **구조만으로는 부족합니다.** 프롬프트에도 `NOT a marker` 선언을 반드시 넣으십시오.
> 프리비즈에 들어간 것은 AI 에게 기본적으로 **전부 교체 대상**으로 해석됩니다 (교훈 165).

## 이 장면이 표현하는 것
대표님 지시(CEO-51) 원문:

> "세 프로젝트 문서에서 같은 역할 단어만 붉게 떠올라 한 곳으로 모이는 것이
> 화면에서 실제로 일어나야 했네요."

- 마젠타 / 시안 / 옐로 평면 = 세 프로젝트 문서
- 붉은 한글 텍스처 plane 3개 = 세 문서에 **반복되는 같은 역할 키워드**(「조율자」)
- 전반 40% = 마커가 문서 위에 **정지** (관객이 세 문서를 읽을 시간)
- 후반 60% = 세 마커가 **떠올라 한 점으로 수렴**
- 카메라 = 좌→우 104도 스윕 + 하강 (문서들의 원근이 계속 변함 = 컷 내부 모션)

## 프롬프트 골격
