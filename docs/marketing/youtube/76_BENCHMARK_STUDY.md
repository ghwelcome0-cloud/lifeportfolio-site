> **[CEO-73]** *"벤치마크를 해도 내 것으로 소화해서 우리의 목적에 맞게 더 높은 품질로

## §1. ★최대 발견 — 벤치마크 6/6 이 「follow-the-object」다★

**6개 벤치마크 전부가 「하나의 오브젝트를 카메라가 물고 따라가는」 서사를 쓴다.**

| 영상 | 관통하는 오브젝트 |
|---|---|
| `Sp8XFlq4s-g` | **빛나는 물방울 하나** — *"The glowing blue water acts as a constant visual anchor throughout every shot"* |
| 내장쇼츠 (인체) | **분자 하나** — 카메라가 관을 따라 물고 간다 |
| `Awl_Uv2ZJ6k` (귀공자) | 추격 대상 인물 |
| `K4YuwHHGrgQ` | 드론 → 3D 단면으로 이어지는 동일 구조물 |
| `-OHeRVGeiPQ` | 조립되는 단일 제품 |
| `fUpBnpzL0co` | 프리비즈 ↔ 최종의 동일 샷 |

### 우리 결함 진단

숏폼 C 의 6컷 주연은 이렇게 바뀐다:

```
cmptab -> card -> card -> brief -> posting -> res
```

**컷마다 다른 소도구를 보여준다.** 이것이 [CEO-76] *"장면만 바뀌는 셈이면 아무리
퀄리티가 좋아도 영상의 몰입감은 없을 거에요"* 의 **정체**다.
G4/G5/G6/G7/G8/Z-FIT 은 **컷 하나하나**의 품질을 재지만, **컷 사이의 서사 연속성**은
어느 게이트도 재지 않는다.

### 처방 — 우리 말로 번역

내장쇼츠 분석이 우리에게 직접 준 조언:

> *"Instead of a molecule in a stomach, follow a Data Packet through a Digital
> Nervous System... using the same macro-3D cutaway and glowing path overlays"*

**우리 번역: 「이력서 한 장(또는 한 문장 카드)」이 6컷을 관통해야 한다.**

| 대상 파일 | 처방 |
|---|---|
| `sets.py` `PROPS` | 6 beat 가 **같은 오브젝트 id** 를 공유하도록 재설계 |
| `scenejobs.py` `gaze_of()` | 시선점이 그 **한 오브젝트**를 계속 물게 (현재는 beat 별 최근접) |
| `script_gate.py` | **신설 G9(ANCHOR GATE)** — 연속 컷의 주연 id 가 바뀌면 경고 |

**⚠ 이것은 큰 설계 변경이다.** 게시 1건을 낸 뒤 착수한다 — [CEO-80](C)
"게시 0건" 이 더 급한 결함이다.

## §3. 내장쇼츠 — 건축 외 영역 (인체 해부 3D)

[CEO-80] 이 *"건축 뿐만 아니라 다른 영역까지"* 라고 지목한 정확한 사례.
`web_search` 로 발견 → 채널 단위 정밀 분석.

### 4단 서사 구조 (그대로 이식 가능)

| 단계 | 시간 | 내용 |
|---|---|---|
| 1. **Intake** | 0~2s | 물질이 입구로 들어간다 |
| 2. **Descent** | 2~10s | 카메라가 관을 따라 **이동**한다 |
| 3. **Interaction** | 10~40s | **한 입자에 카메라를 고정**하고 벽에 닿는 반응을 본다 |
| 4. **Consequence** | 40~60s | 줌아웃 → 장기 전체 상태 변화 + 요약 |

**우리 숏폼 C 로의 번역:**

| 단계 | 우리 컷 |
|---|---|
| Intake | 이력서 한 장이 비교표 위에 놓인다 |
| Descent | 카메라가 그 장을 따라 서가/책상으로 이동 |
| Interaction | 그 장의 **한 문장**에 고정 — "두 번째 문장" |
| Consequence | 줌아웃 → 선택 전체 맥락 + CTA |

### 조판 규칙 (측정된 수치)

| 항목 | 내장쇼츠 | 우리 현재 |
|---|---|---|
| 서체 | Heavy Korean Gothic | NanumGothicBold ✅ |
| 색 | 흰색 + **노란 하이라이트** | 흰색 `INK=(241,241,241)` — **노란 강조 미적용** |
| 위치 | 상단중앙 1/3 | `SUB_Y=1330` (하단) — 검토 필요 |
| 세로 프레임 점유 | **15~20%** | `glyph_h/frame_h` 0.0885~0.1893 ✅ **부합** |
| 씬당 문장 수 | **한 문장** | 1~3줄 한 문장 ✅ |
| 외곽 | 검은 드롭섀도 / 아우터글로 | 패널 배경 — 대안 |

### 페이싱

- **카메라가 절대 멈추지 않는다** ⇒ 우리 `SPEED GATE` 의 `MIN_ARC_DPS=4.5` 와 동일 사상 ✅
- **자막 2~3초마다 교체** ⇒ 우리 4.3초 — §2 처방과 같은 방향
