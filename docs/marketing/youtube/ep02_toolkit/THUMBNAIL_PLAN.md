# EP.02 썸네일 v2 — 벤치마크 근거와 A/B 계획

## 근거 (확인한 출처)
- YouTube 고객센터 "A/B test titles & thumbnails" (support.google.com/youtube/answer/16391400)
  - 썸네일·제목은 최대 3개까지 동시에 시험할 수 있음. 승자는 클릭률(CTR)이 아니라 **시청 시간 점유율**로 정함.
  - 서로 비슷한 안은 결론이 늦게 나므로 **확실히 다른 안**을 시험하라고 권장.
  - 1280×720보다 작으면 시험 안 전체가 480p로 낮아짐.
  - 데스크톱 YouTube Studio에서만 가능하고, 고급 기능 활성화가 필요함.
  - 결과가 나오기까지 최대 2주.
- YouTube 고객센터 "Add custom thumbnails" (answer/72431): 권장 3840×2160, 16:9, JPG/PNG, 모바일 업로드는 2MB 이하.
- 업계 가이드 (vidIQ 2026-07, 1of10 2026-05, Snappa 2026-07):
  - 핵심 아이디어 한 개, 주제 하나, 2~3가지 색.
  - 굵은 글자 3~5단어.
  - 휴대폰 목록 크기에서도 읽혀야 함.
  - ※ 이 항목은 업체가 자체 집계한 경험칙이고, 공식 데이터가 아님.

## 적용
- 목적은 "다이어리 서비스 출시" 하나. 가격·무료 문구는 뺌.
- 글자는 2~4단어 크게 쓰고, 보조 한 줄을 둠. 실제 서비스 화면을 그대로 노출함.
- 시청 시간으로 판정되므로, 영상 첫 장면·내용과 다르게 보이는 낚시 문구는 쓰지 않음.
- 세 안은 약속하는 내용이 서로 다르게 구성함:
  - V1 (추천 기본안): **NEW 출시 / 내 다이어리** — 서비스 이름과 출시를 알림.
  - V2: **리포트가 / 다이어리로** — 리포트에서 이어진다는 변화를 보여 줌.
  - V3: **1년을 담는 / 나만의 한 권** — 결과물(한 권)을 약속함.

## 운영
1. 업로드할 때 V1을 기본 썸네일로 올리고, Studio의 A/B 테스트에 V1·V2·V3(각 3840×2160)를 등록합니다. 처음 올린 안이 무승부일 때의 기본값이 되므로 V1을 맨 앞에 둡니다.
2. 시험 중에는 제목·썸네일을 수정하지 않습니다. 수정하면 시험이 자동으로 멈춥니다.
3. 결과가 나오면 이기는 문구 유형을 EP.03 썸네일 틀로 사용합니다.
