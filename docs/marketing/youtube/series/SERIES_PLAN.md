## 1. 목표
- 일곱 가지 변화(밝힘·지음·펼침·돌봄·이음·세움·지킴)마다 **가상의 한 사람**이 고유함을 12주 동안 자산으로 남기는 과정을 보여 준다.
- 시청자가 「내 일상에서는 무엇이 이 변화일까」를 대어 볼 수 있게 한다. 마지막은 리포트 XI장과 다이어리 길찾기로 이어진다.
- 근거 자료: 다이어리 해설서 「일곱 가지 변화 자세히 보기」(assets/js/diary-help.js CHANGES), 리포트 XI장 자산·직업 예시(assets/js/asset-path.js), 자산화 맞춤 실행 프로그램 12주 구조.

## 6. 자막 개선 (대표 요청 1)
- 새 규칙 `subwrap.py`: 문장 전체를 형태소 분석(Kiwi)해서 어절 경계마다 끊어도 되는지 점수를 매깁니다.
- 끊지 않는 곳: 꾸미는 말 뒤(쓰일 / 때, 처음 쓰이는 / 자리), 의존명사 앞(것·수·때·가지), 보조용언 앞, 명사+명사(고유성 / 기반), 서비스 이름(자산화 맞춤 실행 프로그램 등).
- 끊는 곳 순서: 문장 끝 > 쉼표 > 연결어미(-고·-며·-면) > 주어·목적어 조사. 두 줄은 길이를 비슷하게, 한 줄 7자 미만 금지.
- EP.03 대본으로 시험: 옛 방식의 어색한 줄바꿈 25곳 → 새 방식 0곳.

## 7. 병렬 진행 (대표 요청 3)
| 단계 | 병렬 | 걸리는 시간(예상) |
|---|---|---|
| 대본 7편 | 동시에 | 대표 검토 포함 |
| 이미지·배경 영상·녹음·배경음악 | 7편 동시에 요청 | 1~2시간 |
| 렌더(영상 합치기) | 이 작업 공간은 CPU 2개·메모리 4GB라 **한 번에 1편** | 편당 약 1.5시간 → 7편 약 10~11시간 |
| 점검·업로드 | 편마다 렌더 직후 | 편당 20분 |
- 디스크 여유가 1~2GB라, 한 편이 끝나면 올리고 작업 파일을 지운 뒤 다음 편을 렌더합니다.
- 렌더까지 완전히 병렬로 하려면 작업 공간을 따로 여러 개 띄워야 해서, 그 방법은 대표 승인이 필요합니다(추가 비용).
