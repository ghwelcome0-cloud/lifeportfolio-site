## 2. 세계: 동네의 벽돌·나무 건물 한 채
방마다 서비스를 하나씩 맡깁니다. 1층 서재 = 리포트·길찾기, 2층 모임방 = 실행 프로그램, 옥상 정원 = 싹·이삭·열매, 창밖 풍경 = 일터와 지역.
샷 흐름은 **바깥 → 단면 → 안으로 밀고 들어감 → 저녁 단면으로 다시 전체** (전체 → 단면 → 깊은 확대 → 회수). 모든 배경은 Seedance 2.0 fast i2v, 720p, 6초.

## 3. 새 기법: 매치무브 삽입 (tk/track.py + render.py insert())
1. 배경 영상 속 책자 면적을 사각형으로 지정합니다.
2. KLT 광학 흐름으로 점을 따라가고, RANSAC 호모그래피를 프레임마다 이어 붙입니다(6프레임마다 또는 점이 300개 미만이면 다시 심음).
3. 실제 리포트 페이지를 그 면에 붙이고, 배경의 저주파 밝기와 따뜻한 색을 맞춘 뒤 필름 그레인을 입힙니다.
4. 호모그래피 「다이브」로 페이지를 화면 높이 92%까지 확대하고, 실제 서비스 화면으로 녹아 들어갑니다.
- 품질 기준: 재투영 오차 중앙값 0.15px 이하일 때만 씁니다. R11 = 0.093px(사용), R11b = 0.331px, 왼쪽 책자가 미끄러져 삽입을 빼고 배경으로만 사용.

## 4. 메모리 (4GB 샌드박스)
디코딩한 영상을 통째로 캐시하면 OOM으로 죽습니다. 프레임을 JPEG로 압축해 보관하고 필요할 때만 풉니다(EncClip, LRU 20). 렌더는 60초 단위 조각으로 나누고 `.ok` 표식으로 이어서 합니다(tk/run_render.sh).

## 5. 음성 처리 (tk/vo_prep.py)
문장 사이 0.6초, 문단 사이 0.85초로 줄이고, 1.03배 템포(rubberband). highpass 70 · EQ(250 −1.5, 140 +1, 3800 +2) · 디에서 · 컴프 2.4 · 리미터 0.89.
BGM은 사이드체인으로 낮추고 loudnorm −16 LUFS / −1.5 dBTP. 결과 −15.9 LUFS.

## 7. 배경 반동 금지 (대표 피드백 2026-10-13)
- 문제: 6초 배경 영상을 앞으로 재생한 뒤 거꾸로 되감는 방식(핑퐁)을 썼더니, 긴 장면 후반에 카메라가 왔던 곳으로 되돌아가는 「반동」이 보였습니다.
- 해결: **앞으로만 재생.** 장면 길이에 맞춰 6초 영상을 느리게 늘립니다. 프레임 사이는 광학 흐름 보간(DIS)으로 채워 끊김이 없게 합니다. 아주 느려지는 장면에는 같은 방향의 느린 밀어 들어가기(최대 5.5%)를 더합니다.
- 점검: 수평 움직임 방향이 바뀌는 횟수 = 0 (S02 26초 시험), 1.5초 멈춤 0.

## 8. 썸네일 V1 배경 교체 (대표 피드백 2026-10-13)
- 처음 고른 이유: 영상 전체 세계(건물 한 채, 1층 서재 = 리포트·길찾기)와 같은 그림으로 이어 보이게 하려고.
- 문제: 「서재에서 길을 찾는다」는 생각을 한 번 거쳐야 해서 바로 와닿지 않음.
- 교체: 새벽 언덕길의 갈림길과 이정표. 「길찾기」가 그림만으로 읽히게. 색감(딥 그린 + 골드)과 구성은 그대로.
- 원칙: 썸네일은 영상 세계관보다 **제목 단어가 그림으로 바로 보이는지**를 먼저 봅니다.

## 9. 메시지 몰입을 위한 원칙 (대표 지시 2026-10-13: 「전달하려는 메시지에 몰입하도록 모든 작업을 수렴」)
연구 근거와 적용을 짝지어 둡니다. 근거는 일반 원리이며, 우리 영상에서 효과를 따로 잰 것은 아닙니다.
| 원리 | 근거 | 적용 |
|---|---|---|
| 일관성(군더더기 줄이기) | Mayer, *Multimedia Learning* — 관련 없는 그림·소리를 줄이면 이해가 좋아짐 | 카드·성경 구절·칩이 뜨는 동안 배경을 흐리고 12% 어둡게(「초점 이동」). 내용과 배경이 동시에 시선을 다투지 않게 |
| 신호 주기 | Mayer — 핵심을 표시하면 찾는 수고가 줆 | 말하는 순간 금색 테두리, 숏츠 자막은 말하는 단어를 금색으로 |
| 움직임의 시작은 시선을 끈다 | 주의 연구(움직임 시작·방향 전환은 자동으로 시선을 끎) | 배경은 앞으로만, 같은 방향으로. 방향이 바뀌는 반동 제거 = 쓸데없이 시선을 뺏기지 않게 |
| 시간 맞춤 | Mayer — 말과 그림을 동시에 | 카드·테두리를 말하는 단어 시각에 맞춤(단어 단위 타이밍) |
| 화면 가장자리 정리 | 영상 문법(비네트) | 가장자리를 22%까지 은은히 어둡게, 시선이 가운데로 |
| 숏츠 안전 영역 | 숏츠 하단 UI | 화면 카드는 고정 창 안에서만 스크롤, 브랜드·자막과 겹치지 않음 |
