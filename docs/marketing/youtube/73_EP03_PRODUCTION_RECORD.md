## 2. 세계: 동네의 벽돌·나무 건물 한 채
방마다 서비스를 하나씩 맡깁니다. 1층 서재 = 리포트·길찾기, 2층 모임방 = 실행 프로그램, 옥상 정원 = 싹·이삭·열매, 창밖 풍경 = 일터와 지역.
샷 흐름은 **바깥 → 단면 → 안으로 밀고 들어감 → 저녁 단면으로 다시 전체** (전체 → 단면 → 깊은 확대 → 회수). 모든 배경은 Seedance 2.0 fast i2v, 720p, 6초.

## 3. 새 기법: 매치무브 삽입 (tk/track.py + render.py insert())
1. 배경 영상 속 책자 면적을 사각형으로 지정합니다.
2. KLT 광학 흐름으로 점을 따라가고, RANSAC 호모그래피를 프레임마다 이어 붙입니다(6프레임마다 또는 점이 300개 미만이면 다시 심음).
3. 실제 리포트 페이지를 그 면에 붙이고, 배경의 저주파 밝기와 따뜻한 색을 맞춘 뒤 필름 그레인을 입힙니다.
4. 호모그래피 「다이브」로 페이지를 화면 높이 92%까지 확대하고, 실제 서비스 화면으로 녹아 들어갑니다.
- 품질 기준: 재투영 오차 중앙값 0.15px 이하일 때만 씁니다. R11 = 0.093px(사용), R11b = 0.331px, 왼쪽 책자가 미끄러져 삽입을 빼고 배경으로만 사용.

## 4. 메모리 (4GB 샌드박스)
디코딩한 영상을 통째로 캐시하면 OOM으로 죽습니다. 프레임을 JPEG로 압축해 보관하고 필요할 때만 풉니다(EncClip, LRU 20). 렌더는 60초 단위 조각으로 나누고 `.ok` 표식으로 이어서 합니다(tk/run_render.sh).

## 5. 음성 처리 (tk/vo_prep.py)
문장 사이 0.6초, 문단 사이 0.85초로 줄이고, 1.03배 템포(rubberband). highpass 70 · EQ(250 −1.5, 140 +1, 3800 +2) · 디에서 · 컴프 2.4 · 리미터 0.89.
BGM은 사이드체인으로 낮추고 loudnorm −16 LUFS / −1.5 dBTP. 결과 −15.9 LUFS.
