## 0. ★ 직전 판정 정정 — "종합 상한 88.0, 90 산술 불가" 는 **제 오독이었습니다**

### 0-1. 무엇을 잘못 읽었나

원문 §4 각 축의 `(e) 개선안` 표를 저는 "축별 상한 1개" 로 읽었습니다. 표를 행 단위로 다시 열어 실측한 결과, **모든 행이 각각 `현재점수 → X` 형식의 독립 조치별 추정치**였습니다.

| 축 | 현재 | 원문 (e) 개선안 행 (전량) |
|---|---:|---|
| ① | 73 | 잔존 추상 6곳 일상어 변환 `73→80` · **행동 라벨 도입 `73→82`** · 커스텀 시각 앵커 `73→85` |
| ② | 79 | 축별 "당신만의 특징" 1문장 `79→85` · 강점 조합 시너지 `79→83` |
| ③ | 83 | 완료기준 표현 변주 `83→88` · 실행보드 디지털화 `83→90` |
| ④ | 88 | Notion 템플릿 `88→92` · 웹 대시보드 `88→95` |
| ⑤ | 67 | 재검사 파일럿 `67→72` · SME 패널 `67→75` · 예측타당도 설계 `67→80` |

**모든 행의 좌변이 동일한 현재 점수입니다.** 즉 `85/85/90/95/85` 는 "전량 실행 결과" 가 아니라 **각 축에서 델타가 가장 큰 단일 조치 1건의 값**이었습니다.

### 0-2. 정정된 산술

| 모형 | ① | ② | ③ | ④ | ⑤ | 종합 |
|---|---:|---:|---:|---:|---:|---:|
| 제 직전 (오독) | 85 | 85 | 90 | 95 | 85 | **88.0** ← 폐기 |
| 단일 최대 조치만 | 85 | 85 | 90 | 95 | 80 | 87.0 |
| 단순 델타 합산 | 101 | 89 | 95 | 99 | 93 | 95.0 |
| **보수 모형** (최대 + 나머지×0.5) | **93.0** | **87.0** | **92.5** | **97.0** | **86.5** | **91.20** |

보수 모형 채택 이유: 조치 간 기전 중복(예: ① 3조치가 모두 "직관성" 을 건드림)을 감쇠 반영. **그래도 종합 91.2 로 90 을 넘습니다.**

**⇒ 90 은 산술적으로 도달 가능합니다. 제 직전 보고의 "불가" 판정을 철회합니다.**

### 0-3. 다만 ②축이 병목으로 바뀝니다

보수 모형에서 90 미달 축은 **② 87.0 하나**입니다. 원문이 ②축에 조치를 2개만 준 것이 원인이고, 이는 원문의 조치 목록이 완전하지 않다는 뜻입니다. **②축 추가 조치 설계가 별도 과제**입니다 (§3-2).

### 1-1. 단계별 ⑤축 점수 (전건 실측)

환산식 = `가중합 / 90 / 5 × 100` (원문 §8.2 재현 검증 완료: `320/90 = 3.5556 → 71.11`, 원문 71.1 과 일치)

| 단계 | 점수 벡터 (항목1~8) | 가중합 | ⑤축 | 필요 자원 |
|---|---|---:|---:|---|
| 현재 | `4 3 3 4 3 3 4 4` | 320 | **71.11** | — |
| **P1** 인증 불필요 4항 5점화 | `5 3 3 5 3 3 5 5` | 370 | **82.22** | **0원** |
| **P2** + SME 패널 (항목3) | `5 3 5 5 3 3 5 5` | 390 | **86.67** | ~300만원 / 2~3개월 |
| **P3** + 대체검증 3항 4점화 | `5 4 5 5 4 4 5 5` | 420 | **93.33** | 대체 검증 도구 |

**⇒ P1 만으로 ⑤ 71 → 82. 돈 한 푼 없이 +11점.**
**⇒ P3 에서 ⑤ 93.33. 외부 감사·ISO·EFPA 0건으로 90 초과.**

### 1-2. P1 이 왜 0원인가 — 항목별 실측 근거

**항목 1 (가중 15%) → 5점: 실증 완료.** 5점 요건 3개 중 2개는 이미 충족, 1개는 지면 문장 추가뿐입니다.

```
난수 API 호출 실측 (주석 제거 후 — 결함 DE 회피):
  assets/js/report-engine.js       → Math.random / getRandomValues  0 건
  assets/js/report-engine-v4.js    → 0 건
  assets/js/program-engine.js      → 0 건
  ★ 3엔진 합계 0 건

결정론 실증 (동일 입력 2회 생성 → generatedAt 제외 SHA-256 비교):
  리포트   1회차 5d2d9567fb57c58e / 2회차 5d2d9567fb57c58e  ✅
  프로그램 1회차 7df4ee19096d06dc / 2회차 7df4ee19096d06dc  ✅
  ★ 동일 입력 → 완전 동일 산출 PASS
```

미충족은 **"지면에 명시"** 1건뿐 ⇒ 리포트 IX장 문장 추가로 해결.

**항목 4 (가중 15%) → 5점: 데이터 준비 완료.** 5점 요건 = "전체 매핑을 공개".

```
매핑 커버리지 실측:
  questions.json  totalQuestions 76 / core 56 / other 20 / meta 2
  sections 수집 문항 ID 56건
  mapping.json questionMapping 엔트리 76건
  ★ 56 / 56 매핑 = 100%, 미매핑 0건
```

현재 지면은 Q13·Q39·Q41·Q47·Q49·Q73 **6문항만** 공개 ⇒ 원문 판정 "전체 56문항 매핑은 미공개" ⇒ **전체 매핑 표를 지면에 싣기만 하면 5점.** 데이터는 이미 있습니다.

**항목 7 (가중 10%) → 5점.** 4개 요건 중 3개 충족(라벨 없음·심리검사 주장 안 함·지면 명시). 미충족 = "**금지 표현 목록 운영**". 우리는 `docs/seo-submission-guide.md` 의 `forbidden` 리스트 + `kakao-channel-operations-guide.md` §1.6 6범주 차단어를 **이미 빌드 게이트로 운영 중**입니다 ⇒ 이를 **공개 문서로 게시**하면 5점.

**항목 8 (가중 10%) → 5점.** 3개 요건 중 2개 충족. 미충족 = 효과 미검증 고지의 완결성 ⇒ X장 "이 리포트가 하지 않는 것" 절 보강.

### 1-3. ★ 대체 검증 도구 설계 — P3 의 실체 (대표님 지시 핵심)

원문이 "외부 감사 / ISO / EFPA" 를 요구하는 3항목(2·5·6, 가중 합 30%)에 대해, **인증을 대신하는 검증 장치**를 설계합니다. 각 항목의 5점 요건을 분해하면 인증은 요건 중 **1개**이고 나머지는 우리가 충족 가능합니다.

| # | 5점 요건 분해 | 우리 충족분 | 인증분 | 대체 검증 도구 | 목표 |
|---|---|---|---|---|---|
| 2 | ㉮ 전 문항 변별 ㉯ 대규모 표본 충돌 0 ㉰ 외부 감사 | ㉮㉯ 가능 | ㉰ | **재현 절차 전면 공개 + 제3자 독립 재현 (심층리서치 에이전트가 우리 절차로 직접 재현)** | 3→4 |
| 5 | ㉮ 기술 매뉴얼 외부 공개 ㉯ 제작 규칙서 공개 ㉰ EFPA 등급 | ㉮㉯ 가능 | ㉰ | **기술 매뉴얼·제작규칙서 공개 게시 + EFPA Test Review Model 항목별 자기평가 공표(채점자 분리)** | 3→4 |
| 6 | ㉮ 배포 전 게이트 ㉯ 회귀 테스트 ㉰ 외부 감사 ㉱ ISO 인증 | ㉮㉯ 가능 | ㉰㉱ | **게이트 로그·회귀 결과 공개 + ISO 10667 조항 대조표 자기선언 공표** | 3→4 |

원문이 이 설계를 **직접 허용**합니다 (§8.1 머리글):
> "본 채점표는 AERA/APA/NCME … EFPA Test Review Model(2025), ITC Guidelines, Buros … ISO 10667 에서 도출된 객관 기준을 바탕으로 설계됨. **매년 반복 적용하여 개선 추이를 증명하는 스코어카드로 사용 가능.**"

§8.3 이 채점자 요건도 규정합니다:
> "심리측정학적 배경이 있는 **제3자(학술 위원회 또는 외부 컨설턴트)가 채점하는 것을 원칙**으로 함. 자체 채점 시 '자체 채점' 명시 필수."

**⇒ 우리의 대체 검증 = 「심층리서치 에이전트를 제3자 채점자로 고정 + 절차·근거 전면 공개 + 프레임워크 조항 대조표 공표」.** 이는 공개채점표 규격서 v0.2 §A10 의 강제 3조건(루브릭 사전공개 / 원문 공개 / **채점자 분리**)과 정확히 일치합니다.

### 1-4. 단서 — 5점(만점)이 아니라 4점을 목표로 하는 이유

대체 검증은 인증을 **갈음**하지 않습니다. 인증이 요건인 5점은 정직하게 포기하고 4점을 확보합니다. 그래도 ⑤ 93.33 입니다. **"공인 인증" 표현은 원문 §8.4 가 "허위" 로 명시했으므로 절대 사용 금지.**
