## 1. 수학으로 본 병목 — "입력은 10³⁷가지, 출력 문장은 7가지"

| 측정 | 값 | 뜻 |
|---|---|---|

**결론:** 고유성이 낮은 원인은 설문의 정보량 부족이 아니다. 설문은 10³⁷가지를 구분할 수 있는데, **그 정보를 문장으로 바꾸는 규칙이 7개뿐**이고 **문항 15개는 읽지도 않는다.** 병목은 100% 엔진 쪽(변환 규칙 층)에 있다.

## 2. 왜 "규칙을 더 쓰는" 방식으로는 못 푸는가 (못 풀던 수학 문제의 성격)

현재 규칙은 사람이 손으로 쓴 `if(has('Q63',…)&&has('Q65',…)) put(...)` 형태다. 이 방식의 한계:
- 조합 폭발: 문항 2개 조합만으로도 수백 가지, 3개면 수만 가지 → 사람이 한 문장씩 쓸 수 없음
- 쓴 만큼만 고유함: 규칙 7개 → 문장 7종. 규칙 70개를 써도 70종. 10³⁷에 비하면 0
- 자유 생성(LLM 즉석 작문)은 **금지 원칙** 위반(응답 밖 단정·추측·비재현). 또 Q90 계약은 "같은 답 → 같은 리포트"(계산 재현성 증명됨)를 전제

즉 **"재현 가능하고(결정적), 응답 밖 단정이 없고(근거 결박), 그런데도 10³⁷에 비례해 다른 문장이 나오는"** 변환이 필요하다. 이것이 지금까지 못 풀던 문제의 정확한 형태다.

## 3. 해법 원리 — 조합 생성(compositional generation): 문장을 "쓰는" 것이 아니라 "조립"한다

AI 모델이 어려운 수학 문제를 풀 때 쓰는 원리와 같다: **전체 답을 한 번에 외우지 않고, 검증 가능한 작은 단계(lemma)를 조립하되 각 단계가 독립적으로 참인지 확인한다.** 리포트에 옮기면:

1. **문항 → 의미 단위(semantic atom)**: 선택형 22문항의 선택지 전부(약 230개)에 각각 "관찰 가능한 사실 1줄 + 축 + 역할(조건/수단/기준/장면/대상)"을 **사람이 사전에 결박**한다. 자유 생성이 아니라 **사전 등록 사전(lexicon)**이다. 230개는 사람이 검수 가능한 분량.
2. **역할 문법(role grammar)**: 축마다 가설 문장의 **빈칸 틀**을 정한다. 예) 자기실행: `[장면]에서 [수단]으로 시작하고, [조건]이 있을 때 이어 갑니다.` — 틀은 축당 3~5개, 역할 슬롯은 선택지의 역할 태그로 채운다.
3. **조립 규칙(composition)**: 응답에서 각 축으로 매핑된 선택지의 의미 단위를 역할별로 모으고, 틀의 빈칸을 **결정적 순서**(문항 번호 → 선택지 순)로 채운다. 같은 답 → 같은 문장(재현성 유지). 조합 수 = 틀 수 × 슬롯별 후보 수의 곱 → 축당 수천~수만 문장, 네 축 조합은 10⁸ 이상.
4. **근거 결박**: 문장의 모든 빈칸은 `evidenceRefs`(문항 ID)로 역추적 가능. 응답에 없는 말은 들어갈 수 없다(원칙: 응답 밖 단정 0).
5. **충돌·미확정 처리**: 같은 역할에 상반된 단위가 오면(예: '혼자 있는 시간' vs '사람들과 함께') **단정하지 않고 "두 조건을 비교"하는 틀**로 분기(기존 `compare-supported-methods` 원칙 그대로). 기타(직접 입력)는 현재 `clarification-required` 경로 유지.
6. **직관성 보장**: 틀은 사람 말로 사전 작성(한 문장, 25자 내외 KO / 15단어 EN). 조립 결과가 틀 길이 상한을 넘으면 슬롯 수를 줄이는 결정적 축약 규칙 적용.
7. **맞춤 실행 프로그램**: 같은 의미 단위에 "실행 1개 · 완료 기준 1개 · 돌아볼 질문 1개"를 함께 결박 → RQ-01 카드 고리(가설→실행→완료→질문)가 축마다 응답에서 조립된다.

**검증 가능성(수학 문제의 "증명" 단계):** (a) 결정성 — 같은 입력 2회 → 바이트 동일, (b) 근거성 — 모든 문장 토큰이 lexicon 항목 또는 틀 고정어 (자유 토큰 0), (c) 다양성 — 무작위 1000명에서 축별 서로 다른 가설 ≥ 500, 네 축 모두 결정 ≥ 95%, (d) 금지어 0, (e) 길이 상한 100%, (f) 기존 byte-pin·저장본 비파괴. 전부 기계 게이트로 고정 가능.
