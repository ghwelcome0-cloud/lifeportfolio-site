# RQ-04 진단 — IX. 내 답변과 결과 이해하기 (고객 관점 · X장 "발견→살아냄→남김" 맥락 정합)

- 작성: 2026-10-09 · 상태: **구현 완료 (브랜치 rq04/ix-review) · §4 실측 결과 추가** · 측정: `tools/report-quality/render.cjs` KO/EN 375px p13 실측 + Q90 1회차 judge 근거 문구(점수 아님, 관측 사실만 인용)

## 0. 한 줄 결론
IX장은 "회사가 스스로 정직함을 증명하는 페이지"로 쓰여 있고, 고객이 **X장(한 문장 고르기 → 한 가지 해 보기 → 한 줄 남기기)** 을 하는 데 필요한 재료는 절반만 있다. 블록 7개 중 **고객 자산에 직접 쓰이는 것 2개, 조정하면 쓰이는 것 2개, 성능표(G17)/해설서로 옮길 것 3개**다.

## 2. 개선안 (A5 정직성은 그대로, 고객 자산으로 재배치)

### 2-A. IX = "내가 준 것 → 리포트가 만든 것" 대조 페이지로 좁힌다
1. **인용 6행 유지**(원문 그대로 실린 답).
2. **VII 네 영역 근거행 추가** — `report._axisProjection.axes[k].evidenceRefs` + `facts[Q].values`(이미 엔진이 산출, 재계산 없음):
   `자기이해 ← Q7 "다른 사람과 이야기 할 때" · Q13 "배려·성취"` 식으로 영역당 1행. Q90 judge가 "evidenceRefs는 있는데 고객이 확인할 경로가 없다"(A5.4 c3·c4 관측)고 적은 바로 그 빈칸이다. 기록 응답이 없는 Q는 행에서 제외하고 "답하지 않은 문항은 쓰지 않았습니다"를 명시(A2 c1 지적 해소).
3. **선택 규칙 1문장**: "영역마다 답한 문항 중 그 영역에 배정된 것만, 질문 순서대로 썼습니다. 쓰지 않은 문항 N개는 지수 계산에만 쓰였습니다."(`coverage.notInterpreted.length` 실측값) — A5.4 c3 '선택규칙·미공개범위' 직접 대응.
4. **정정·문의 경로 1줄**: "내 답이 잘못 옮겨졌다면 마이페이지 하단 고객센터 이메일로 (영업일 24시간 내)" — 공개 연락처 DLP 정책(`contracts/public-contact-policy.json`)상 주소 원문은 승인 페이지(mypage 등)에만 실리므로 리포트·해설서는 위치를 가리킨다 — A5.7 c2 '이의제기 안내 없음' 대응. 기존 mypage 문구 재사용.
5. 제목 유지, 리드 문장 교체: "리포트의 모든 문장은 아래 답에서 나왔습니다. 맞지 않는 문장이 있으면 그 줄의 내 답을 먼저 보세요." (X장 1단계 '한 문장 고르기'와 연결)

### 2-B. 이동
- `mp-steps`·`mp-repro` → X장(이미 같은 내용 있음 → IX 쪽 삭제만).
- `_mapAll`·`_noSay`·`mp-note` 2줄 → `report-guide.html`(해설서) + G17 공개 성능표. IX에는 각 1줄 참조.
