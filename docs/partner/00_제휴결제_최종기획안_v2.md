## 4. 회원가입과 제휴 회원 확인
- 로그인 전: `회원가입하고 혜택 받기` / `이미 회원이에요 · 로그인`. 가입·로그인 후 같은 제휴 페이지로 돌아옵니다(로그인 화면의 돌아가기 허용 목록에 `partner/…` 추가).
- 결제는 로그인한 우리 계정으로만. 이미 결제한 계정은 막고 마이페이지로 안내.
- 확인 방식은 제휴마다 선택: ① 링크만 ② 공통 제휴 코드 ③ 1인 1코드. 모든 방식에 최대 인원·기간이 걸립니다.
- 스포츠잡알리오: **② 공통 제휴 코드**. 스포츠잡알리오가 회원 공지(회원 메일, 카페 회원 게시판 등)로만 코드를 알립니다.

## 5. 모방 링크 차단 (운영 대시보드에서 만든 링크만 작동)
1. **등록된 제휴만 작동**: 제휴 설정은 운영 대시보드(운영자 권한)에서만 만들 수 있습니다. 등록되지 않은 주소(`/partner/아무이름`)는 "찾을 수 없는 페이지"만 보이고 가격·결제 버튼이 나오지 않습니다.
2. **링크 키**: 대시보드가 링크를 만들 때 추측할 수 없는 링크 키를 붙입니다. 예: `lifeportfolio.co.kr/partner/sportsjobalio?k=Q7m2…` 키가 없거나 틀리면 1번과 같은 화면. 기업 이름을 알아도 링크를 흉내 낼 수 없습니다.
3. **키 다시 만들기**: 링크가 엉뚱한 곳에 퍼지면 대시보드에서 `링크 다시 만들기` → 옛 링크는 바로 작동 중지. 새 링크를 제휴사에 다시 전달.
4. **가격은 서버에서만**: 주소·화면 값을 바꿔도 금액은 바뀌지 않습니다(6장).
5. **결제는 우리 사이트에서만**: 다른 사이트가 비슷한 화면을 만들어도 결제는 되지 않습니다. 페이플은 등록 도메인(`lifeportfolio.co.kr`)에서 온 요청만 승인하고(현재 코드의 Referer 검사), 페이팔 주문은 우리 서버만 만듭니다.
- 남는 위험(사실): 진짜 링크를 그대로 복사해 퍼뜨리는 것은 막을 수 없습니다. 이 경우는 제휴 코드 + 최대 인원·기간으로 막습니다. 최대 손해는 "최대 인원 × 할인액" (스포츠잡알리오: 500 × 6,900원 = 3,450,000원).

## 6. 결제 흐름 (기술)
1. 페이지가 서버에서 제휴 설정을 읽습니다(링크 키 검사). 없음·멈춤·종료·기간 밖이면 안내만.
2. 로그인·코드 확인 후 서버가 **30분짜리 확인표**를 만들고 인원 한 자리를 먼저 잡습니다.
3. 페이플: 확인표 금액으로 결제창을 열고, 서버가 페이플 최종 승인 **전에** 확인표(본인·기간·상태·금액)를 다시 검사. 틀리면 승인하지 않아 돈이 빠지지 않습니다.
4. 페이팔: 서버가 확인표 해외가로 주문을 만들고 캡처 때 금액을 다시 검사.
5. 결제 완료 기록에 제휴사·제휴가·확인표 번호를 함께 남기고 자리를 "사용"으로 바꿉니다.
6. 이후는 지금 결제 완료 후 처리와 같습니다.
- 30분이 지나면 잡아 둔 자리는 풀립니다.
- 기존 일반 결제(19,900원·$14.99)는 코드 경로를 나눠 바뀌지 않게 합니다.

- 고객이 결제창을 스스로 닫은 경우는 보이지 않습니다(그냥 다시 시도 가능).

**문구 원칙**: 고객 잘못처럼 들리지 않게 / 기술 용어·"한도" 단어 쓰지 않기 / 돈이 빠지지 않았다는 안심을 먼저 / 달러 결제의 차이는 숨기지 않고 정직하게 / 다시 시도할 길도 남기기.
