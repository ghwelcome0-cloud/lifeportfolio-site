# r4 — 대표님이 직접 하실 때 (10분, 복사-붙여넣기 3번)

## 왜 해야 하나 (한 문단)

공개 비교표의 E1(직접 측정) 칸은 "우리가 같은 도구로 각 회사 첫 화면을 재서 적은 값"입니다. 40개 중 **9개(고용24 7·어세스타 2)는 국내 IP에서만 열려서**, 해외에 있는 제 작업 컴퓨터로는 접속 자체가 안 됩니다. 그래서 그 9칸이 "미측정"으로 비어 있고, 이것이 E1 25% 중 약 6%p를 깎고 있습니다. **국내에 있는 컴퓨터(대표님 PC)에서 같은 측정기를 한 번 돌리면** 그 9칸이 채워집니다. 측정기는 한 글자도 바꾸지 않고, 결과를 보고 다시 돌리지도 않습니다 — 그래야 "같은 자로 쟀다"가 성립합니다. 팀(TL·Peer·Method)이 조건을 전부 미리 못 박아 두었고(G21 §24), 대표님은 **실행만** 하시면 됩니다.

## 준비 (한 번만)

1. **Node.js**가 없으면 https://nodejs.org 에서 "LTS" 내려받아 설치 (다음→다음→완료).
2. 키트 파일 `e1-r4-kit.tar.gz`를 받아 **바탕화면에 풀기**(Windows 11: 우클릭 → 압축 풀기 / Mac: 더블클릭). `q90-kit` 같은 폴더가 생깁니다.

## 실행 (복사-붙여넣기)

**Windows** — 시작 메뉴에서 `PowerShell` 열고, 아래를 그대로 붙여넣고 Enter:
```powershell
cd "$HOME\Desktop\q90-kit"; node runs\run-r4.cjs
```

**Mac** — `터미널` 열고:
```bash
cd ~/Desktop/q90-kit && node runs/run-r4.cjs
```
(실행기는 Node 스크립트 하나입니다 — PowerShell 인코딩 문제를 피하기 위해.)

화면에 `== 1/6` … `== 6/6` 이 차례로 나옵니다. **5/6 단계는 3~10분 걸립니다** — 그냥 두세요.
중간에 한 번 `네트워크 종류`를 물으면 `home-wifi` / `office-wired` / `mobile-tether` 중 하나를 치고 Enter.

> 중요: 끝까지 **한 번만** 돌리세요. 실패한 행이 나와도 다시 돌리지 않습니다(규칙). 중간에 끊겼으면 알려 주세요.

## 보내기

폴더 안에 생긴 **`r4-result.tar.gz` 파일 하나**를 파이스 컴퓨터 DM(또는 저에게)에 올려 주세요. 화면 맨 아래 찍힌 두 줄(측정기 sha, tar sha)도 같이 복사해 주시면 됩니다.

## 하지 말 것

- `tools/` 안 파일 열어서 고치지 않기 (sha가 바뀌면 자동으로 중단됩니다).
- VPN 켠 채로 돌리지 않기 (국내 IP여야 합니다).
- 결과 파일 손대지 않기.

## 자주 생기는 일

- "`node`를 찾을 수 없습니다" → Node.js 설치 후 PowerShell/터미널을 **새로** 열고 다시.
- "sha가 다릅니다" → 키트가 손상된 것. 다시 받으세요.
- 일부 행이 `timeout` → 그대로 보내 주세요. 국내에서도 안 열리는 사이트면 그것도 사실로 적습니다.
