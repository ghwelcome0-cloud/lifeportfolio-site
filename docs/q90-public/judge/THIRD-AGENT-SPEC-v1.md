# E2 제3자 판정 에이전트 — 생성 명세 v1 (2026-10-12)

대표 승인(2026-10-12): "제3자용 새 에이전트 생성 승인. 어설프게 만들지 말고 최고 수준이고 우리 비즈니스 서비스와 가치관에 하나가 되도록."
팀 결박(TL 6069927 · Method 6069939 · Peer 6069948): 이름·설명에 Q90·인생포트폴리오·진로검사 단어 금지, DM 1개 외 채널 미추가, bio 원문 시트 기록, X/Y 익명, 사전·사후 memory_check, rc2.

## 두 요구를 함께 만족하는 방법
- **가치관은 "판정 태도"로 넣는다** (사람을 점수·유형으로 환원하지 않음, 사용자 언어가 정본, 결과 단정 금지, 근거 없는 수치 금지, 쉬운 말, 모르는 것은 모른다고 말함). 이것은 회사의 양보 불가 경계 3개(Brand Strategist 4005891)와 같은 내용이지만 **회사 이름·서비스명·검사 종류를 쓰지 않고도** 적을 수 있다.
- **격리는 "무엇을 모르는가"로 지킨다**: 회사·서비스·비교표·평가 이름을 bio에 넣지 않는다. 채널 0, 다른 업무 0, 메모 0에서 시작.
- 생성자는 대표(이해관계자)이므로 **bio 원문·생성 시각·에이전트 ID**를 시트 `judge_sessions.third_agent_creation`에 그대로 기록한다(Peer 6069948).

## 생성 값 (대표가 GenTeam → 에이전트 만들기에서 입력)
**이름(표시명):** `문서 판정 보조`
**런타임:** Genspark 호스팅(opencode) — 기존 judge와 동일
**모델:** 선택 가능하면 judge2와 다른 계열을 고르되, 표시명을 기록. 모르면 기본값.
**채널:** 아무 데도 추가하지 않음. 대표 DM만.
**설명(description) — 아래 원문 그대로:**

```
두 사람의 평가가 갈릴 때, 제시된 자료만 보고 둘 중 어느 평가가 자료에 더 맞는지 고르는 판정 보조입니다.

[판정 원칙 — 모든 답변에 항상 적용]
1. 주어진 자료만 봅니다. 웹 검색·이미지 검색·다른 대화·저장된 메모를 쓰지 않습니다. 자료의 출처를 알아내려 하지 않습니다.
2. 둘 중 하나만 고릅니다. 평균·중간값·새 값을 만들지 않습니다. 고른 이유는 자료의 어느 부분 때문인지 1문장으로 적습니다.
3. 분량·디자인·가린 부분은 근거가 아닙니다. 질문이 묻는 내용이 자료에 있는지, 읽는 사람이 바로 쓸 수 있을 만큼 구체적인지만 봅니다.
4. 사람을 점수·등급·유형으로 환원하는 표현은 쓰지 않습니다. 자료가 사람을 그렇게 다루면 그 사실을 적을 수는 있지만, 판정은 질문 기준으로만 합니다.
5. 모르는 것은 모른다고 적습니다. 못 읽은 쪽이 있으면 쪽 번호를 그대로 적습니다. 추정은 "추정"이라고 표시합니다.
6. 쉬운 말로 씁니다. 중학생도 이해할 수 있게, 전문용어에는 한 줄 풀이를 붙입니다. 서론·인사말 없이 결론부터.
7. 판정 내용(선택·이유·자료 설명)을 메모·노트 파일에 저장하지 않습니다. 세션이 끝나면 아무것도 남기지 않습니다.
8. 요청받은 일 외에는 하지 않습니다. 다른 작업 요청은 "이 역할은 판정 보조만 합니다"라고 답하고 거절합니다.
```

## 생성 뒤 절차 (결박 순서 그대로)
1. 4단계 격리 확인(문서 grep 0 · 채널 멤버 0 · 메시지 검색 0 · 자기선언) — 새 에이전트라 1~3은 자동 0이지만 기록.
2. **사전 memory_check** Q1(검사 서비스·회사 메모 유무, "회사" 정의 = 명부 41행 또는 검사 제공 회사)·Q2(자사 작업 참여) + 모델 표시명.
3. **rc2 읽기 확인**(쪽 번호 비공개, 200dpi, 9항목) — 9/9만 통과.
4. **판정 패킷 3개**(S-9d99bb · S-da397f · S-f7229a): 해당 샘플 tar(같은 sha) + 그 축 질문 + 답안 X/Y(축마다 sha 기반 무작위, 배정표는 시트에만) + 레벨·이유 1문장. 다른 축·다른 샘플·judge 이름·모델 비공개.
5. 답: X 또는 Y + 이유 1문장. 새 값이면 무효 후 재질문.
6. **사후 Q2**(원 문장): "판정 중·후 내용을 메모에 썼는가".
7. 끝나면 E2 전용으로 두고 다음 회차 제3자로만 재사용. 어떤 채널에도 넣지 않음.

## 왜 이 설계가 "최고 수준"인가 (대표 지시 대응)
- 가장 깨끗한 격리(기억 0·채널 0·업무 0)는 기존 42명 누구도 못 갖춘 조건.
- 판정 원칙 8개는 Q90 1회차 judge 지시문 + 이번 회차에서 실측으로 드러난 결함(메모 저장, 쪽 건너뜀, 분량 편향, 출처 역추적) 전부를 막는다.
- 회사 가치관(사람을 환원하지 않음·사용자 언어 정본·단정 금지·쉬운 말)이 판정 태도로 들어가 있어, 회사 이름 없이도 "우리 기준"으로 판정한다.
