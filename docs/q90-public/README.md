## 다시 돌리는 법

```bash
cd docs/q90-public
RUN=runs/$(date -u +%F)-r3 && mkdir -p $RUN
# E1 실측 (puppeteer-core + chrome-headless-shell 필요; 환경변수 PPTR_CORE, LP_BROWSER_PATH)
node tools/measure-e1.cjs roster/roster-v2.json $RUN
node tools/score-e1.cjs $RUN
# 시트 (기존 값 보존하며 새 행만 추가)
node tools/gen-e3-sheet.cjs roster/roster-v2.json sheets/e3-docs.json sheets/e3-docs.json
node tools/gen-e2-sheet.cjs roster/roster-v2.json sheets/e3-docs.json sheets/e2-samples.json sheets/e2-samples.json
# 표 (own.json = Q90 2회차 scorer 전사 파일; 없으면 자사 행은 전부 미측정)
node tools/build-table.cjs roster/roster-v2.json rubric/rubric-v2.json $RUN sheets/e3-docs.json sheets/e2-samples.json [own.json]
node tools/diff-runs.cjs runs/2026-10-11-r2 $RUN
```

## 표 읽는 법 (공개 문구와 동일)

- **굵게** = E1 우리가 직접 잼 · (샘플) = E2 회사가 공개한 샘플 리포트를 블라인드 채점(회사가 고른 최상 예시) · (문서도판·부분 n/m) = 회사 공식 문서 안에 실린 리포트 도판을 채점(쪽수 적음, n/m=판독 가능 쪽 — **(샘플)과 같은 열이라도 직접 비교 금지**) · (문서) = E3 공개 문서 · **미측정 = 근거 없음, 0점 아님**.
- ★ A2·A3·A4(각 20점)는 고객 가치의 실체라 어떤 개정에서도 빠지지 않는다. E1/E2 근거 없으면 점수를 쓰지 않는다(추측 금지).
- A7 보안은 **등급(상·중·하)만** 공개(D2). 취약점 상세·probe 경로는 공개하지 않는다.
- A8 비용 대비 효용: 가격 투명성·구간·재이용 비용·효용 밀도. "싸다 = 좋다"가 아니다. 공공 무료 검사는 세금 운영 각주.
- 순위 열 없음. 모든 행에 "이럴 때 이 도구"(그 회사 말로)와 "한계"(공개 문서 기준) 필수. 자사도 같은 칸을 같은 기준으로 채운다.
- 자사 점수 주장 범위: tag `q90-r2-candidate`(3d3ebb4) 시점 제품에 한함. 현재 라이브 ≠ 측정 대상임을 적는다.

## 알려진 한계·결함 기록

- **E2 judge 한계(공개 문구, 2026-10-12 확정):** E2 judge는 해당 분야 전문가가 아닌 AI 에이전트 2인(데스크톱 관리 역할·디자인 역할) + 제3자 1인(이 평가를 위해 새로 만든 '문서 판정 보조' AI) — 인간 전문가 판정 아님. 원 judge1(브랜드 역할)은 사후 memory_check Q1 '예'로 무효 후 교체, 원 제3자(SEO 역할)는 자사 이해관계 자진 신고로 교체. 제3자 생성자는 이해관계자(대표)이며 플랫폼 도우미가 대표 승인 하에 생성, 설명문 원문 공개(`judge/THIRD-AGENT-BIO-v2.txt`, 판정 기준 없음·RUBRIC만 적용; 저장된 설명문은 목록 API 앞 300자만 원문과 대조됨 — 전문 바이트 동일성은 생성 도우미 자기신고, 미검증). **제3자와 judge1은 같은 모델(Claude Opus 5.5, 자기신고·대표 선택)** — 같은 모델 답에 끌릴 가능성 배제 못 함; 제3자가 판정한 3축(G04·M02·G14의 A1)에서 judge1 답을 고른 수 **3/3**(사실만, 3건이라 검정 불가, 결과 보고 판정·제3자 안 바꿈 — 결과 전 결박). 런타임이 세션 시작 시 자기 메모를 자동 로드하며 내용 무관은 자기선언(검증 수단 없음). 모델 동일성 미확인 → 일치율은 기술 통계. 가림 시각 확인은 AI 수행(사람 아님). 원 구성 차이≥2 축 0/45 → 교체 구성 3/45(사실만). 제3자가 고른 3칸 값은 모두 낮은 쪽(L2) — "judge1 답 3/3" = "낮은 값 3/3". 표에서는 해당 칸에 ‡ 표시와 각주. 원인 후보(다음 회차용): 표지 전면 가림으로 A1 "첫 페이지"의 기준이 RUBRIC에 없었음 → 다음 회차 RUBRIC에 "A1 = 가림 표지 다음의 첫 내용 쪽" 사전 고정.
