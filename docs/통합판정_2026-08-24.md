### 2-1. 관리자 콘솔 접속 불가 — **완전 해소**

**실측 (리퍼러 행렬 · 2026-08-24)**

```

https://lifeporfolio-admin.firebaseapp.com/  200               ← 이전 403

https://evil.example.com/                    403   ★ 통제군 — 제한 여전히 작동
```

**★ 통제군을 함께 측정한 이유** — 만약 `evil.example.com` 도 200 이었다면,
그것은 "허용목록이 추가된 것"이 아니라 **"제한이 통째로 해제된 것"** 이다.
그 경우 화면상 성공처럼 보이면서 실제로는 API 키가 전 세계에 열린다.
결함 BT(거짓 초록불은 거짓 빨간불만큼 위험하다)에 따라 음성 통제군을 의무화했고,
그 결과 대표님의 조치가 **정확히 좁게 추가된 것**임이 확인됐다.

**최종 실측** — 관리자 4지면 `/admin` `/b2b-admin` `/checkin-admin` `/review-admin` **전부 200**,
보안 헤더 12/12, 서버 권한 게이트 401/403, 그리고 **대표님이 실제로 로그인해 기능 확인 완료.**

이것은 명칭 변경이 아니라 **평가 대상 변경**이다.
⇒ **척도가 다른 구간을 이어 붙인 Before/After 서사는 그 순간 전체가 무효**가 된다.
71.6 → 95.2 서사를 대외에 쓰면, 이 한 가지가 발견되는 순간 나머지 전부의 신뢰가 무너진다.

**따라서 판정** — **오늘 기준, 대외 공표 가능한 5축 수치는 존재하지 않는다.**
- [1] = superseded · 내부 자평 · 외부 미검증 · 대외 인용 금지 (문서 자체 명시)
- [3] = `internal_only` (점수 대외 금지 · 실측치와 재현 명령만 유효)
- [7] CEO 종합보고서 = **점수를 싣지 않고 게이트명·실측값·재현명령만** 기재 → **대외 인용의 표준 형식**

⇒ 대외 자료는 **[7] 형식만** 쓴다.

### 3-3. 🟡 보안 — 2건 (측정 완료 · 판단 대기)

**(1) 권한 회수 기능 미구현**

대표님 단독 운영 중에는 실질 위험이 낮으나,
**직원·외부인에게 권한을 부여하는 시점에는 반드시 선행 구현해야 한다.** (대표님 지시로 연기됨)

안전 순서: **실사용 며칠 → 위반 리포트 확인 → 0건이면 승격.**
