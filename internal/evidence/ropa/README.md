# ROPA evidence

Internal, non-hosted evidence for the LifePortfolio data map and Records of Processing Activities (ROPA).

- `data-map-v0.1.md` — repository-grounded narrative inventory
- `registry.v0.1.json` — machine-readable activity registry
- `vendor-evidence-checklist.md` — safe collection checklist for facts outside this repository

This directory is not a compliance approval artifact. Unknown facts remain unknown until verified. Never commit secrets, raw customer data, vendor exports, tokens, screenshots containing identifiers, or private URLs here.
