있을 거에요. 그걸 체크해주는 표시하면 좋을 것 같아요. 그래야 고객들이 더욱
객관적이고 신뢰 있게 바라볼 수 있고, 우리도 향후 검증을 받기 위한 동기부여가 돼요."

해소해서 전문성과 신뢰도 평가축 점수를 높였으면 좋겠습니다."

【2】 v0 → v0.2 무엇이 바뀌었나 (5개)

(1) §1-3 개정 — L2(외부 인증)를 "없으니 논외" 에서 "채점 항목" 으로 전환

(2) §3-0 신설 — A0 제3자 검증 이력 (점수 없음 · 체크 표시만)
    표기 4종: 보유 / 없음 / 확인불가 / 진행중
    보유 인정 조건 = 기관명·연도·URL 3개 전부 있을 때만. 하나라도 없으면 보유 불가.
    점수화하지 않는 이유 = ISO 27001(정보보호)과 EFPA(측정 타당도)는 서로 다른 것을
    보증하므로 합산 불가.
    우리 칸은 정직하게 "없음". A0 를 넣는 것이 우리가 인증받았다는 뜻이 절대 아닙니다.

(3) §1-4 신설 — LLM 비교 채점표 벤치마킹 (총괄이 실물 2건 확보해 이미 정리해 둠)
    (가) Artificial Analysis — 9개 벤치 가중치 공개 / 95% 신뢰구간 공개 / 한계 자인 /
         가격은 환산식(7:2:1) 공개로 점수화
    (나) aizolo 5종 비교표 — 채점 축 9개 명시, 기업 축에 SOC 2·ISO 27001·HIPAA
         제3자 인증 보유 여부를 비교 항목으로 사용
    ⇒ 대표님 "체크 표시" 지시가 업계 표준 관행임이 실증됨. 이것이 A0 의 외부 근거입니다.

(4) §3-1 — A9·A10·A11 신설 (개수를 늘린 게 아니라 LLM 표에는 있는데 우리 표엔
    비어 있던 자리를 메운 것)
    A9  응답–결과 일관성   (LLM 표 accuracy 대응)
    A10 산출물 자체의 품질 (writing quality / research depth 대응)
    A11 완주 가능성·지원   (speed 대응)
    context window 는 대응물이 없어 탈락, 사유를 §3-3 에 기록.

(5) §3-4 신설 — A8(가격 대비) 조건부 점수화 재검토
    v0 은 "주관 개입하므로 점수화 불가" 였으나, AA 가 환산식·가정을 전부 공개하는
    방법으로 가격을 점수화하는 반례를 확인. 3조건 충족 시에만 점수화.

개수 정리: v0 = 채점 축 7 + 참고 열 1 / v0.2 = 채점 축 10(A1~A7·A9~A11) + 참고 열 2(A0·A8)
개수는 목표가 아니라 결과입니다. "충분한가" 만 따진 결과가 10+2 였습니다.
