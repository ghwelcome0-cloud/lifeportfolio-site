■ 결론부터
여러분이 이전에 만들어 주신 이미지 4장(사무실 단면 / 수직 필터 컬럼 / 산업 인테리어 /
아이소메트릭 디오라마)의 ★한글 처리 방식이 대표님 기준으로 유일한 정답★ 이었습니다.
제가 ffmpeg 로 글자를 얹었더니 대표님이 "글자 퀄리티는 따로 놀아요. 저급이에요" 로
반려하셨고, 여러분 이미지를 역추적한 뒤 원인을 규명했습니다. 공유합니다.

■ 역추적 결과 — 여러분이 옳았던 이유
저는 글자를 "영상 위에 잘 그리기"로 접근했습니다. 이건 원리상 실패합니다.
여러분은 두 방향으로 푸셨습니다.

 (1) ★문서 본문은 글자를 아예 그리지 않는다★
     굵은 진회색 블록 = 제목 / 얇은 중간회색 바 = 본문 / 컬러 바 = 강조
     읽을 수 있는 글자가 단 하나도 없습니다. 그래서 어긋날 여지가 없습니다.
     강조 팔레트 실측: 시안 #66C5E3 / 페일옐로 #FCE17B / 코랄 #F29496 / 세이지 #B4DB8D

 (2) ★전달용 한글은 씬의 오브젝트로 만든다★
     둥근 반투명 다크 글래스 슬래브
     + 얇고 균일한 시안 네온 외곽선(+ 미세 외부 글로우)
     + 씬 소점에 맞춘 3D 원근 기울기 (평면 스티커가 아니라 방 안의 물체)
     + 아래 지면으로 떨어지는 실제 드롭섀도 (키라이트 방향 일치)
     + 주변 종이·목재에 시안광 반사
     + 상단 엣지 스페큘러 하이라이트

 ★핵심: 글자는 "렌더 대상"이 아니라 "씬에 존재하는 물체"입니다.★
 ffmpeg 오버레이는 원리상 (2)를 못 합니다. 평면이고 씬과 무관하기 때문입니다.
 그래서 앞으로 ★모든 한글은 이미지 생성 단계에서 유리 패널로 구워 넣습니다★.

■ 확정 스펙 (앞으로 전 콘텐츠 공통 규칙)
  · 모델 고정: gpt-image-2 (대표님 지시 — 글자 정확도 최상)
  · 해상도 2k · 참조 이미지를 image_urls 로 ★반드시 직접 전달★
    (텍스트로 스펙만 서술하면 9.5 가 안 나옵니다. 제가 그렇게 해서 7/10 받았습니다)
  · 서체: 모던 지오메트릭 한글 산세리프 볼드, 평평한 획
    (Noto Sans KR Bold / Pretendard Bold 성격)
  · 넉넉한 자간, 단일 행, 패널 안 광학적 중앙, 사방 여유 패딩
  · 글자는 순백에 가깝게 + 은은한 시안 발광 림
  · ★패널 내부에 장식 요소 금지★ — 밑줄/구분선/아이콘/점 전부 제거
    (제 1차 시안이 장식 수평선 때문에 8.8 로 감점됐습니다)
  · 글자 뒤 유리를 살짝 더 어둡게 → 네온 글로우가 글리프를 흐리지 않도록
  · 자체 검수 기준: 글자 craft ★9.0/10 이상★ 이어야 통과.
    미달이면 재생성. (제 최신 시안 실측: 9.0 / 8.8 → 개선 재시도 중)

        → 더미 절개 시작. 층 사이에서 같은 형태의 바가 반복 발광(시안).
