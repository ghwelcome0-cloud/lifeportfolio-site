# 앵커 관객 검증 스위트 (CEO-83)

> **[CEO-83]** *"조건 카드 한 장 좋습니다. 다만 그 설정이 정말 관객들에게(유튜브
> 시청자들) 몰입과 호응을 줄 수 있는 수준과 기획인지는 검증하세요."*

**교훈 213**: 게이트를 통과하는 앵커와 관객을 붙잡는 앵커는 다른 질문이다.
`script_gate.py`(G1~G8/Z-FIT)는 「대본대로 배치·촬영되었는가」를 재고,
이 스위트는 **「시청자가 그것을 붙잡을 수 있는가」**를 잰다.

## 실행 (전부 무료 · 렌더 불필요)

```bash
cd /home/user/lf/r3d          # 원본 파이프라인 위치
python3 -u <이 디렉터리>/audit.py      # 현 앵커가 6컷에서 어떤 상태인가
python3 -u <이 디렉터리>/contrast.py   # 축① 시각적 구별성 (WCAG 대비비)
python3 -u <이 디렉터리>/visib.py      # 축② 변화 가시성 + 축③ 0~2초 후킹
python3 -u <이 디렉터리>/needsize.py   # 축④ 26초 지속력 (필요 크기 역산)
python3 -u <이 디렉터리>/altsweep.py   # 축⑤ 대안 후보 스윕
python3 -u <이 디렉터리>/proto.py      # 처방 사전 반증 (교훈 206)
```

모든 산식은 `script_gate` 와 **같은 값**을 쓴다 (교훈 208):
`frac = 2*max(sc0,sc1)*lens / (depth*36.0)`
