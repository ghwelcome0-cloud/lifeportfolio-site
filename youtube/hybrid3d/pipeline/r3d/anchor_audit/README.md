## 추가 도구 3종 (CEO-84 이행 중 신설)

### `recolor.py` — 축① 무채색 대비 스윕

대본이 **"중성 카드만 남김"** 을 요구하므로 발광/유채색 앵커를 쓸 수 없다(교훈 214).
무채색(채도 <= 0.03) 안에서만 앵커색 × 이웃색 조합을 전수 스윕한다.

```bash
python3 recolor.py
```

**결과 (정본)**

| 색 | 휘도 | 채도 | 책상 대비 | 바닥 대비 |
|---|---|---|---|---|
| 현행 `DOC_N` 중성회색 | 0.273 | 0.03 | 5.2:1 | 5.6:1 |
| `DOC_W` 백지 A4 | 0.562 | 0.03 | 9.9:1 | 10.6:1 |
| **A2 밝은 중성 0.94** | **0.864** | **0.01** | 14.8:1 | 15.9:1 | ← **앵커 채택** |
| **N3 어두운 종이 0.28** | **0.063** | 0.03 | 1.8:1 | 2.0:1 | ← **이웃 채택** |
| N4 어두운 종이 0.22 | 0.039 | 0.03 | 1.4:1 | 1.5:1 | ← **배제 (책상에 묻힌다)** |

**A2 × N3 = 8.11:1** (현행 1.90:1 의 4.3배). 채도 0.01 = 무채색 = 대본 준수.
⚠ **단 이것은 알베도 상한이다. 렌더에서는 1.29 로 압축된다** → `anchorpx.py` 로 반드시 재검증 (교훈 217).

### `anchorpx.py` — ★렌더 프레임 앵커 픽셀 직독★ (교훈 217 의 도구)

**`pixel_check.py` 로는 v6 를 검증할 수 없다.** 그 마스크는
`(sat>=55) | ((lum>=170)&(sat<=40))` = **「밝은 종이 아무거나」** 인데,
v6 는 종이를 **두 등급(앵커 0.94 / 이웃 0.28)** 으로 갈랐기 때문에
「밝은 것 아무거나」로는 앵커를 특정할 수 없다 (교훈 212: 측정 도구도 검증 대상이다).

```bash
# mp4 인코딩 후 프레임 PNG 디렉터리는 비워진다 -> ffmpeg 로 추출
ffmpeg -v error -i J_A3-13.mp4 -vf "select=eq(n\,0)" -vframes 1 -y J_A3-13_p0.png
python3 anchorpx.py             # 또는  python3 anchorpx.py "J_A3-13*.png"
```

**판정 2축**

| 축 | 산식 | 하한 |
|---|---|---|
| 화면 점유 | `frac = max(bw,bh) / W` | **>= 0.14** (G6 와 동일) |
| **고립비** | `iso = L1 / L2` (최고 휘도 덩어리 / 2등) | **>= 1.35** |

- 마스크 `(sat <= 45) & (lum >= 95)` = **무채색 + 종이급 밝기**
- 덩어리를 **면적이 아니라 평균 휘도로 재정렬** ⇒ 가장 밝은 것이 앵커
- `scipy` 가 없으므로 연결 성분은 손 flood fill (`MINPX = 300`)
